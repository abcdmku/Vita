This is a genuine web view (a second CEF browser surface inside the desktop), but scoped to offline, local content only (the vita://browser origin). A strict CSP (connect-src 'none') blocks every network request — there is no path to the open internet. It is honest about scope: a working local browser, not a full internet browser.
