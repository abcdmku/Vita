About this web surface

The Vita Browser is a real CEF web view embedded in the desktop, scoped for safety:

  • CAN render bundled local pages over vita://browser
  • CAN render same-origin assets (SVG, CSS, images, fonts)
  • CAN navigate between local pages
  • CANNOT reach the open internet (allowed_network: false)
  • CANNOT issue cross-origin requests (strict CSP connect-src 'none')

Honest about scope: a working local/offline browser, not a full internet browser.
