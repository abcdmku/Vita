# Vita — Mobile UI kit

Phone-framed recreations (390pt frame). Each links `../../styles.css` + `kit.css`.

| Screen | Theme | Shows |
|---|---|---|
| `index.html` (Home) | Light | Clock widget, app grid, blurred dock |
| `Lock.html` | Dark | Lock clock + notification stack + quick actions |
| `Settings.html` | Light | Grouped settings list (rows, values, switches) |
| `ControlCenter.html` | Dark | Connectivity block, music, focus/rotate, sliders |
