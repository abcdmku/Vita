# SDK core audit — 2026-06-20

Multi-agent adversarial audit (workflow `sdk-core-audit`, 6 dimensions × adversarial verify, 23
agents) of `sdk/typescript` after the Phase-0 SDK core (P0-001..P0-009). 17 raw findings → **15
confirmed**. Fixed via cleanup contracts P0-010..P0-012.

## Major
1. **envelope.ts — `verifyEnvelope` is a recomputable unkeyed hash, not authenticity.** `seal`/
   `verify` naming overstates the guarantee (it only detects accidental corruption / stale-hash). It
   also never structurally validates `env.plan` is a well-formed `CanonicalPlan`. Real signing
   belongs to the TCB/Go agent (spec §7.1, §16). → Rename to honest naming (or document it is
   corruption-detection, NOT a signature) AND structurally validate the plan. *(P0-011)*
2. **capabilities.ts — `AcceleratorCapability` widens the CLOSED spec §14.1 union with `JsonObject &`.**
   Opens each variant to arbitrary extra props; the static type then disagrees with the (closed)
   runtime validator. → Remove `JsonObject &` from each variant. *(P0-010)*
3. **define-system.ts — `DeepReadonly<T>` duplicated verbatim** in capabilities.ts and
   define-system.ts. → One owner, shared. *(P0-010)*
4. **define-system.ts — two different public `DeviceSnapshot` types** (capabilities vs define-system),
   forcing alias imports. → One `DeviceSnapshot` from a single owner. *(P0-010)*
5. **define-system.test.ts — the shipped spec §8.3 example FAILS the SDK's own `validatePlan`,** and
   its test only asserts app IDs/memory, never validation. → Make the example valid + assert
   `validatePlan` passes on it. *(P0-012)*
6. **validate.test.ts — accelerator tamper-detection and embedded-refusal rejection branches have
   zero test coverage.** → Add tests. *(P0-012)*

## Minor
7. capabilities.ts — `bestAvailable` mislabels an explicitly-preferred CPU selection as a fallback. *(P0-010)*
8. repro.ts — `assertDeterministic`/`isDeterministic` misreport a deterministic fn returning
   `undefined`/unsupported types as non-deterministic. *(P0-012)*
9. envelope.ts — integrity does not bind `createdAtRef` provenance into the hash. *(P0-011)*
10. define-system.ts — `AcceleratorSelectionResult` bypassed by longhand union in 3 places. *(P0-010)*
11. capabilities.ts — `bestAvailable` two-form overload asymmetric; single-arg form unused. *(P0-010)*
12. validate.ts — names the device snapshot `caps` vs DeviceSnapshot/snapshot/device elsewhere. *(P0-010)*
13. define-system.ts — `AppOptions` omits `allowedCapabilities`/`capabilities` fields that validate.ts
    treats as first-class app config. *(P0-012)*
14. envelope.test.ts — tamper test covers only stale-hash; schemaVersion/createdAtRef refusal paths
    untested. *(P0-011)*
15. accelerators.test.ts — immutability of returned `prefer`/`available` arrays asserted nowhere. *(P0-012)*
