- `agent/capabilities/pdssync/pdssync.go:163-171`: the monotonic check is a read-validate-write sequence with no lock or compare against the current file at commit. Two concurrent `Apply` calls can both validate against cursor `100`, then write `200` followed by `150`, leaving the live cursor regressed. The contract’s invariant is “sync state never goes backwards”; this needs serialization around read/validate/write or an atomic compare-and-replace facade.
