BLOCKING

- `agent/internal/capmanifest/capmanifest.go` `normalizeStringFormat(..., "rfc3339Instant")` validates the already JSON-decoded string with `time.Parse(time.RFC3339, value)`. That is looser than the real agent entrypoint for escaped JSON strings. `time.Time.UnmarshalJSON` receives the raw quoted JSON bytes and, per Go’s own source, still does not unescape before `parseStrictRFC3339` (`https://go.dev/src/time/time.go`, `https://go.dev/src/time/format_rfc3339.go`). So a raw request like `{"desired":"2026-06-21T01:02:03\u005A"}` is accepted by this manifest path after JSON decoding to `...03Z`, but rejected by `transport.DecodeJSONRequest[nodetime.ApplyRequest]`. This violates the contract’s manifest≡agent requirement and is not covered by `schema/capabilities/conformance/time.json`.
