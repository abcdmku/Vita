BLOCKING

- `agent/capabilities/backup/backup.go:610` / `:614`: `parsePolicy` decodes raw JSON directly into structs. Go’s `encoding/json` accepts duplicate object members with last value winning, so a stored policy like `{"retention":{"count":0,"count":30},...}` or `{"recoveryKeyRef":{"id":"-----BEGIN PRIVATE KEY-----","id":"rk:owner",...}}` is accepted. That violates fail-closed explicit-zero and §13.1 inline-key rejection; `Handle` then also returns the original `Raw` bytes. Reject duplicate keys before normalization, as this is a TCB parser.

- `agent/capabilities/backup/backup.go:49` / `:418`: `RecoveryKeyRef.handle` is optional and only validated when present. P0-020’s `RecoveryKeyRef` requires both `id` and `handle`, and P1-021 says to mirror that model’s recovery-key reference invariants and reject absent required fields. As written, `{"recoveryKeyRef":{"id":"rk:owner-primary"}}` validates and applies. Require `handle` and add a regression test.
