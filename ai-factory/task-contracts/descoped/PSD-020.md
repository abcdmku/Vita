## Objective
Implement the ZERO-COPY texture import the CEF accelerated-OSR path needs (and de-risk the design's #1 concern — vmwgfx
DMABUF/modifier negotiation) — WITHOUT CEF, by round-tripping a GBM-allocated DMABUF through the import path on the real
vmwgfx GPU. The seam already reserves `TextureHandleKind::DrmPrimeFd` (lib.rs:95) but the import is unimplemented.
1. **EGL/GL extension bindings (dlopen, like the existing symbols in linux.rs):** add `eglCreateImageKHR`/
   `eglDestroyImageKHR` (`EGL_LINUX_DMA_BUF_EXT`) and `glEGLImageTargetTexture2DOES` (`GL_OES_EGL_image`); detect the
   required extensions (`EGL_EXT_image_dma_buf_import`(+`_modifiers`), `GL_OES_EGL_image`) and FAILSAFE cleanly if absent.
2. **Import API:** `import_dmabuf_surface(id, width, height, fourcc, modifier, &[planes:{fd,offset,stride}])` → create an
   `EGLImage` from the DMABUF + bind it to a GLES texture (`glEGLImageTargetTexture2DOES`) → register as a compositor
   surface (the `DrmPrimeFd` kind), composited + no-repaint-repositioned like any surface. Validate planes/fourcc/
   dimensions fail-closed.
3. **GBM round-trip self-test (the verification, no CEF):** a mode/test that GBM-allocates a buffer object, fills a known
   pattern, EXPORTS a PRIME fd (`gbm_bo_get_fd` + modifier/stride), IMPORTS it via (2), composites + reads back, and
   asserts the pattern survived the zero-copy round-trip. Emit a marker (e.g. `VITA-DMABUF: import=OK fourcc=... modifier=
   ... status=OK|FAILSAFE reason=...`) so the orchestrator can confirm DMABUF works on vmwgfx (or learn exactly what
   fails — modifier rejection, missing extension, etc.).

## User value
The zero-copy GPU-texture path that makes CEF accelerated-OSR (and WPE) viable at 60fps with no CPU readback — and it
proves DMABUF/EGLImage works on the actual vmwgfx target BEFORE committing to the CEF integration, exactly the PSD-000
de-risk the design called for.

## Non-goals
- NO CEF/web engine here (the PRODUCER is a GBM test buffer; CEF/WPE is PSD-000). NO CPU-readback path (that's PSD-011's
  buffer surfaces). Keep the production OS headless — verification/desktop substrate only.

## Acceptance
`npm run typecheck`; compositor builds for linux (rust-in-docker); cargo tests for the binding/extension-detection +
fail-closed (missing-extension / bad-plane) cases. INDEPENDENT (orchestrator): boot the GBM round-trip self-test on the
3D-accel VMware target — `VITA-DMABUF: import=OK ... status=OK` means zero-copy DMABUF works on vmwgfx; `status=FAILSAFE
reason=...` tells us exactly what's missing (then iterate / fall back to WPE or CPU-readback). State honestly which occurred.

## Security/constraints
- Fail-closed on missing extensions / bad planes / modifier rejection. dlopen (no link-time dep). No remote imports;
  --locked crates; lockfile. Verification/desktop substrate only, not the production OS.

## Definition of done
- DMABUF→EGLImage→GLES import (bindings + extension detection + `import_dmabuf_surface`, fail-closed) + a GBM round-trip
  self-test emitting VITA-DMABUF; cargo tests for bindings/fail-closed; orchestrator confirms the vmwgfx DMABUF result
  honestly. R2 reviewer gate + GPU-boot verification.
