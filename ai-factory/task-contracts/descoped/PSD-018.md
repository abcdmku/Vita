## Objective
The FIRST real-content path (no web engine): a pure, deterministic TypeScript rasterizer that turns the merged shell's
`ShellElement` tree (`sdk/typescript/src/shell/index.ts`) into an RGBA pixel `Surface` buffer — the content producer that
PSD-011's `register_buffer_surface` consumes. This makes windows show ACTUAL content (filled regions + text), offline,
before any CEF/web engine.
- `rasterize(element, width, height) -> { width, height, rgba: Uint8Array }` — render a `ShellElement` subtree to RGBA8:
  filled rectangles from the element rect/zone (reuse `ShellRect`/`ShellPlacement.rect`, shell/index.ts), background +
  border colors, and block stacking of children (simple top-down layout; NO flex/CSS engine yet).
- **Text:** render single-line + wrapped text via a VENDORED fixed bitmap font (check a small monospace bitmap font into
  the repo under sdk/typescript/src/raster — NO remote/system fonts; deterministic glyph blitting). Color + alignment.
- **Deterministic + pure:** identical inputs → byte-identical RGBA (no time, no float-nondeterminism, no ambient I/O).
  Integer coverage; clip to bounds; fail-closed on bad dimensions.

## User value
Turns the colored-placeholder windows into windows with REAL rendered content (panels, labels, text) using Vita's own
TSX shell model — entirely offline, no Chromium. The lighter half of the spec's render strategy; CEF/WPE (PSD-000) later
covers the full web-app class.

## Non-goals
- NO compositor/GPU changes (produce an RGBA buffer; PSD-011 is the GPU sink). NO flex/full-CSS cascade, NO antialiasing/
  alpha-blend sophistication, NO scalable/TTF fonts (later slices). NO web engine. Don't fork PSD-005 shell types — import.

## Acceptance
`acceptance_command` passes: rasterizing a known ShellElement tree yields the expected RGBA (assert specific pixels:
background fill, a border, a glyph's lit pixels, child stacking); deterministic (same input → identical bytes twice);
fail-closed on bad dimensions; comprehensive unit tests. Pure, headless; no boot marker. A later slice wires the output
to PSD-011 buffer surfaces over the seam.

## Security/constraints
- Pure/deterministic, no ambient I/O, vendored font (no remote/system fonts). Bounded output size. No remote imports;
  lockfile; no lifecycle scripts. Reuse PSD-005 ShellElement/ShellRect types.

## Definition of done
- `rasterize()` (rects + colors + block layout + vendored-bitmap-font text → RGBA8) over the merged ShellElement model,
  deterministic + fail-closed, with comprehensive pixel-assertion unit tests + a vendored font; typecheck clean. R1.
