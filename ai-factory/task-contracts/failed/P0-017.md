## Objective
Refactor `validateCapsule` (storage/capsules) to use the canonical `safeNormalize` primitive
(`sdk/typescript/src/safe-normalize.ts`, P0-015) for the untrusted-input handling, instead of its own
ad-hoc intrinsic-safe normalization. Flow becomes: `const n = safeNormalize(input); if (!n.ok) return
reject; /* validate structure/§13.1 semantics on the trusted plain n.value */`. Remove the duplicated
accessor/exotic/cyclic/method-shadow handling now provided by `safeNormalize`.

**Behavior must be IDENTICAL**: every existing test still passes, and the full fail-closed set still
holds (garbage, partial, cyclic, method-shadowed, hostile-iterator, throwing/flipping proxy/getter ⇒
reject, never throw) — plus §13.1 (secrets-as-references, non-empty signatures) unchanged.

## User value
One audited normalizer behind every validator (§18.5 factory improvement) — removes the recurring
boundary-bug surface and shrinks the capsule validator.
