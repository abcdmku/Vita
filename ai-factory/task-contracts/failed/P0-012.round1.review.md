**BLOCKING**
- `sdk/typescript/src/repro.ts:84-149` introduces sentinel objects for `undefined`, `NaN`, `bigint`, etc., but those sentinels collide with legitimate plain-object return values. Example: a function alternating between `undefined` and `{ __vitaDeterminismType: "undefined" }` would serialize identically and be reported deterministic. Same issue exists for `1n` vs `{ __vitaDeterminismType: "bigint", value: "1" }`. This is a false positive in the determinism gate, violating the contract’s “correctly treat” requirement and spec §8.2 determinism expectations. Use a collision-free typed serialization and add negative tests for these collisions.
