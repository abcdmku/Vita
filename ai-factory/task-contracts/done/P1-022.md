## Objective
Register the two newest capabilities — `backup` (P1-021) and `pdssync` (P5-004) — into `agentd`, exactly
like P1-020 wired storage + update. Construct each with its production facade in
`agent/cmd/agentd/main.go` and add them to the registry; add their request decoders to
`DefaultRequestDecoders()` in `agent/transport/server.go` (without a decoder, /apply rejects them with
"no registered request decoder"). After this, all NINE capabilities (nodeconfig, time, hostname, identity,
network, storage, update, backup, pdssync) are discoverable via `GET /operations` and applicable via
`POST /apply`.

## User value
Completes the agent's exposed operation set — backup + PDS-sync become managed operations the controller
can discover + apply (FR-004/007/015/018).
