## Objective
Migrate the `network` capability (op `network.policy` — verify the exact `Name`) end-to-end. The REAL
entrypoint `transport.DecodeJSONRequest[network.ApplyRequest]`+`Validate()` is the ORACLE. Read
`agent/capabilities/network/network.go` and match `normalizeRule`/`normalizeCIDR`/`validInterfaceName`/
`sourceCoversAll` EXACTLY (AGENTS.md manifest≡agent + the 9 traps, incl. trap 9 integer-literal + trap 5b).
- **`schema/capabilities/network.json` = the full request** `{ desired: { object: { allow: array of object
  { proto: enum[tcp,udp]; port: integer-sentinel; sourceCidr: cidrLiteral; interface: networkInterfaceName;
  unsafeWideOpen: boolean OPTIONAL default false } } } }` with the `allow` pointer-slice presence rules.
- **FORMATS / OPTIONS (structured; match the agent EXACTLY; ground-truth cross-check vs network.go):**
  - **`cidrLiteral`** = `normalizeCIDR`: `netip.ParsePrefix(value)` succeeds, canonical form = `prefix.Masked()`
    (host bits MASKED — so it ACCEPTS non-canonical input like `10.0.0.5/24` and NORMALIZES to `10.0.0.0/24`;
    do NOT reject host-bits-set CIDRs). Parity-safe via `net/netip` (extend P9-009's ipLiteral). EXPOSE a
    `coversAll` predicate = `prefix.Bits()==0 && prefix.Addr().IsUnspecified()` (i.e. canonical `0.0.0.0/0` or
    `::/0`) for the cross-field below.
  - **`networkInterfaceName`** = `validInterfaceName`: non-empty AND byte-len ≤ `maxInterfaceNameLength`(15)
    AND `interfaceNamePattern` `^[A-Za-z0-9][A-Za-z0-9_.:-]*$`.
  - **`port` integer-sentinel** (NEW): valid iff `port == PortAll(-1)` OR `1 <= port <= 65535`. Reject `0`,
    other negatives, `>65535`, AND non-integer-literal tokens (`1.0`/`1e3` — AGENTS trap 9). (Existing integer
    min/max is contiguous; this is a sentinel `{-1}` ∪ a range.)
  - **`proto`** = enum {`tcp`,`udp`}; **`unsafeWideOpen`** = boolean, OPTIONAL (absent ⇒ false, matching the
    `omitempty` non-pointer bool — verify the agent treats absent as false, NOT required).
  - **wide-open-guard cross-field (item-level-forbid-unless — the hard one)**: for EACH `allow` rule, REJECT
    iff `port == PortAll(-1)` AND `sourceCidr`'s CANONICAL form covers-all (∈ {`0.0.0.0/0`,`::/0`}) AND
    `unsafeWideOpen == false`. Governed, closed cross-field rule consuming the cidrLiteral CANONICAL output.
- **Conformance ≡ agent** `schema/capabilities/conformance/network.json` (≥ 26 full-request vectors) via BOTH
  the manifest AND `DecodeJSONRequest[network.ApplyRequest]`+`Validate()`. Cover: valid tcp/udp rule, bad
  proto, port 1/65535/PortAll(accept) and 0/-2/65536/`80.0`/`8e1`(reject), non-canonical CIDR (`10.0.0.5/24`
  ⇒ accept+normalize), bad CIDR, v6 CIDR, interface 15/16-byte boundary + bad char, the wide-open guard:
  `port=-1 + 0.0.0.0/0 + unsafeWideOpen:false` ⇒ REJECT, same with `unsafeWideOpen:true` ⇒ ACCEPT, and
  `port=-1 + 10.0.0.0/8 + false` ⇒ ACCEPT (not covers-all), absent allow, dup JSON key, unknown field. The
  REAL entrypoint is the oracle.
- **Register** network (regenerate; orchestrator updates the registry test) + evaluator coverage. Agent UNCHANGED.
