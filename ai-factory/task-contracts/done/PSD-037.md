## Objective
Headless, deterministic view-model for **Global keyboard-shortcut registry**, built ONLY on `@vita/desktop-sdk` public ports (the launcher/command port + a minimal injected keymap) — injected ports, NO
platform internals, NO DOM (pure logic the rendered desktop binds to). Code: `ui_kits/desktop/viewmodels/shortcuts.ts`; test:
`sdk/typescript/test/ui-kits/Shortcuts.test.ts`. Build against CURRENT main (wave-1+2 merged). Import the SDK as
`ui_kits/desktop/package.ts` does; ONLY public exports. If a needed port is missing, define a MINIMAL injected port
interface (typed, fail-closed) fully testable against a fake now.
- A keymap: register(keychord -> command id), detect + report conflicts, resolve a key event to a command, list + rebind, defaults vs user overrides. Deterministic chord normalization (canonical modifier order, case-fold); pure; dispatch resolved commands via the injected command port; fail-closed on unknown commands.

## User value
Extends the Vita desktop BEYOND the imported mockups with real, tested Global keyboard-shortcut registry behavior on the SDK — a complete desktop OS.

## Non-goals
- NO DOM/CSS/CEF, NO platform internals, NO new visual design. Consume ports; don't reimplement them.

## Acceptance
`acceptance_command` passes: deterministic tests cover the described state transitions + fail-closed paths against fakes; typecheck clean.

## Security/constraints
- Injected ports only (no ambient I/O); capability-mediated fail-closed; pure/deterministic. No remote imports; lockfile; no lifecycle scripts.

## Definition of done
- `ui_kits/desktop/viewmodels/shortcuts.ts` + `sdk/typescript/test/ui-kits/Shortcuts.test.ts`, deterministic, typecheck clean. R1.
