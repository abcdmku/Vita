## Objective
A pure, standalone SDK model + fail-closed validators for recovery-key **enrollment, rotation, and
verification** (spec §11, §10.4, FR-015), building on the `RecoveryKeyEnrollment`/`RecoveryKeyRef`
schema already in `backup-model.ts` (P0-020 — import it, do NOT redefine). `recovery-key.ts` exports:
- An N-of-M quorum model (`RecoveryQuorum`: `threshold` ≤ `shares`, both ≥ 1) for recovery shares.
- `validateEnrollment`, `validateRotation` (old set → new set, threshold preserved or owner-approved),
  and `validateRecoveryAttempt` (a set of presented share refs satisfies the quorum) — all fail-closed.
- NEW validators ⇒ use `safeNormalize` for the boundary, then validate on the trusted plain value.
- **Secrets-as-references only (§13.1)**: shares/keys are referenced by id/handle; reject any structure
  embedding literal key material (PEM/seed/private-key/long blobs). Reuse `backup-model`'s ref check.
- Standalone module — import from `backup-model.ts`/`safe-normalize.ts` only; no shared-index edits.

## User value
The typed, validated recovery flow (enroll quorum → rotate → recover) the storage/identity layers and
controller will drive — encodes N-of-M + secrets-as-references at the SDK boundary before any crypto.

## Non-goals
- No real crypto / Shamir split / key generation / network / agent code. Flow types + pure validators
  only. Do NOT modify `backup-model.ts`; import it. No shared-index edits.

## Dependencies
P0-020 (`backup-model` recovery-key schema + ref check) — merged. P0-015 (`safeNormalize`) — merged.

## Acceptance tests
`acceptance_command` — `recovery-key.test.ts` covers: valid N-of-M enrollment validates; `threshold >
shares` rejected; rotation preserving threshold validates, lowering it without approval rejected; a
recovery attempt meeting the quorum accepts, below-quorum rejects; embedded key material rejected
(§13.1); fail-closed on hostile input via safeNormalize. Orchestrator also runs `npm run typecheck`.

## Performance & security constraints
Pure/deterministic, no I/O/crypto/network. Fail-closed via `safeNormalize`. Default-deny: anything not
provably quorum-satisfying is rejected. §13.1 secrets-as-references. Strict TS (no `any`). R2 →
reviewer-gated (recovery is security-critical).
