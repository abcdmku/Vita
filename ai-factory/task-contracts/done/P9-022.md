## Objective
Migrate the `storage` capability (op `storage.*` — verify the exact `Name`) end-to-end — the HARDEST cap (four
whole-list invariants). The REAL entrypoint `transport.DecodeJSONRequest[storage.ApplyRequest]`+`Validate()` is
the ORACLE. Read `agent/capabilities/storage/storage.go` and match `normalizeLayout`/`normalizeSubvolume`
EXACTLY (AGENTS.md manifest≡agent + the 9 traps).
- **`schema/capabilities/storage.json` = the full request** `{ desired: { object: { subvolumes: array of object
  { role: enum[system-state,user-data,app-state,snapshots,local-backup-cache]; path: absolutePath; appId:
  string OPTIONAL; quotaGiB: integer OPTIONAL } } } }` with the `subvolumes` pointer-slice presence (nil ⇒
  reject "subvolumes is required"; JSON null ⇒ reject "must be a list"; empty `[]` ⇒ reject "must contain
  required storage areas").
- **REUSE**: `absolutePath` (P9-012 — it WAS built to equal `isCanonicalAbsolutePath` exactly: `/`-prefixed,
  reject root `/`, no trailing slash, segments non-empty/not `.`/not `..`/no NUL; confirm + reuse). Integer
  with `nullAsAbsent` (P9-021) for `quotaGiB`. `appId` optional string with `nullAsAbsent`.
- **`quotaGiB`** integer **exclusiveMinimum 0** (`> 0` when present; `*int64`), integer-literal (trap 9),
  `nullAsAbsent` (absent OR null ⇒ omitted/ok; present ⇒ must be > 0).
- **FOUR NEW dialect primitives (governed, closed; both planes; match storage.go EXACTLY; ground-truth
  cross-check):**
  - **enum-keyed conditional presence (BOTH directions)**: `appId` is REQUIRED+non-empty WHEN `role ==
    app-state`, and FORBIDDEN when `role != app-state` (normalizeSubvolume:388-394). A per-item cross-field.
  - **singleton-subset (per-enum-value at-most-once)**: the roles in `singletonRoles`
    {system-state,user-data,snapshots,local-backup-cache} may each appear AT MOST ONCE across `subvolumes`;
    `app-state` is UNBOUNDED (may repeat). (normalizeLayout:351-357.)
  - **required-enum-coverage**: EVERY one of the 5 `requiredRoles` must appear ≥1 time (normalizeLayout:368-372).
  - **filtered-uniqueBy**: among the `app-state` subvolumes ONLY, `appId` must be UNIQUE (seenAppIDs:359-365) —
    a `uniqueBy:[appId]` SCOPED to rows where `role == app-state`.
- **Conformance ≡ agent** `schema/capabilities/conformance/storage.json` (≥ 30 full-request vectors) via BOTH
  the manifest AND `DecodeJSONRequest[storage.ApplyRequest]`+`Validate()` (copy the dual-oracle pattern from
  `network_conformance_test.go` — NOT self-referential). Cover: a full valid layout (all 5 roles, multiple
  app-state with distinct appIds); missing a required role (reject); duplicate singleton role (reject);
  duplicate app-state appId (reject); app-state WITHOUT appId (reject); non-app-state WITH appId (reject);
  bad path (root `/`, trailing slash, `..`, relative); quotaGiB 0/negative/absent/null/float-token; appId
  null vs absent vs empty; subvolumes nil/null/empty; dup JSON key; unknown field. The REAL entrypoint is the oracle.
- **Register** storage (regenerate; orchestrator updates the registry test) + evaluator coverage. Agent UNCHANGED.
