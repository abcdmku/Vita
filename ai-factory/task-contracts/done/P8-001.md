## Objective
SDK type model + fail-closed validator for the node's network desired-state (§12): `NetworkInterface`
(name + kind), `InboundRule` (protocol tcp/udp + port + source CIDR), `FirewallPolicy`
(default-deny inbound + an explicit `allow` allowlist + an explicit `unsafeWideOpen` escape), and
`NetworkConfig`. `validateNetworkConfig(input)` uses `safeNormalize`, then validates on the trusted
plain value. Default-deny: reject an implicit allow-all rule unless `unsafeWideOpen`. SDK counterpart to
the agent network capability (P7-001). NOTE (orchestrator §1.1 direct build — Codex substrate
usage-limited): authored + implemented by the orchestrator, R1 self-reviewed + typecheck-gated.

## Acceptance tests
Valid config validates; malformed interface name/kind, bad protocol/port/CIDR rejected with paths;
missing required field rejected (fail-closed, not defaulted); absent `allow` rejected (explicit `[]`
accepted = deny-all); implicit allow-all rejected unless `unsafeWideOpen`; hostile/partial input
rejected via safeNormalize. `npm run typecheck` clean.
