## Objective
SDK type model + fail-closed validators for RAUC A/B updates (§6/§11, FR-023): `SlotState`
(id a|b, active, bootable, version), `UpdateBundleRef` (ref + SRI integrity + version), `UpdatePolicy`
(automaticRollback + maxFailedBoots), `UpdateConfig` (exactly the two slots a+b), and `UpdatePlan`
(targetSlot + bundle). `validateUpdateConfig`/`validateUpdatePlan` use `safeNormalize` then validate.
**Invariants:** exactly two slots {a,b}; exactly ONE active; an UpdatePlan must target the INACTIVE
slot (A/B safety — never overwrite the running slot); bundle integrity is real SRI; versions non-empty;
maxFailedBoots bounded 1-10. Secrets-as-references (bundle referenced + integrity-pinned, never inline).
NOTE (orchestrator §1.1 direct build — Codex substrate usage-limited): authored + implemented by the
orchestrator, R1 self-reviewed + typecheck-gated.

## Acceptance tests
Valid config + plan validate; not-exactly-{a,b} slots rejected; zero or two active slots rejected; a
plan targeting the ACTIVE slot rejected (A/B safety); missing required field rejected (fail-closed);
malformed SRI integrity rejected; out-of-range maxFailedBoots rejected; hostile/partial input rejected
via safeNormalize. `npm run typecheck` clean.

## Definition of done
- [ ] Acceptance passes; typecheck clean.
- [ ] A/B invariants enforced (two slots, one active, plan targets inactive); fail-closed via safeNormalize.
- [ ] Diff within the two target files.
