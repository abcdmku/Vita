## Objective
Migrate the `capsule` capability (op `capsule.registry` — verify the exact `Name`) end-to-end, the WAVE-2
target. The cap's REAL entrypoint `transport.DecodeJSONRequest[capsule.ApplyRequest]` + `Validate()` is the
ORACLE (gold standard — NO vendored-copy oracle). Read `agent/capabilities/capsule/capsule.go` and match it
EXACTLY (AGENTS.md manifest≡agent + the 8 traps). One dialect-touching contract.
- **`schema/capabilities/capsule.json` = the full request** `{ desired: { object: { capsules: array of object
  { id: capsuleId; version: capsuleVersion; integrity: sriIntegrity; state: enum[installed,disabled] } } } }`
  with the pointer-slice presence rules (`capsules` absent ⇒ reject; `null` ⇒ reject; empty `[]` — match the
  agent) and **`uniqueBy: ["id"]`** (agent dedups by `entry.ID`, capsule.go:479). Each entry field REQUIRED.
- **New FORMATS (structured, NO regex engine; match the agent regexes EXACTLY via FROZEN corpora — hard-parity):**
  - **`capsuleId`** = `validCapsuleID` (capsule.go:531): `reverseDNSPattern`
    `^[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?(?:\.[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?)+$` OR `opaqueIDPattern`
    `^[A-Za-z0-9][A-Za-z0-9._:-]{2,159}$`, AND NOT(control char OR the capsule SECRET scanner OR
    `hasInlineReferenceScheme`).
  - **`capsuleVersion`** = `validVersion`: `versionPattern` `^[A-Za-z0-9][A-Za-z0-9.+_-]{0,127}$` AND the same
    NOT(control/secret/scheme) screens the agent applies.
  - **`sriIntegrity`** = `isValidSRI`: `^sha(256|384|512)-([A-Za-z0-9+/]+={0,2})$` THEN base64-decode the
    digest to EXACTLY 32/48/64 bytes — `=`-padded ⇒ `StdEncoding`, else `RawStdEncoding` (capsule.go:587-589).
    Parity-safe via `encoding/base64`; replicate the padded-vs-raw + per-algo-length branch EXACTLY.
  - **the capsule SECRET scanner** (`containsInlineCapsuleMaterial`, capsule.go:438-442+527): privateKey
    (`openssh\s+private\s+key`/literal `age-secret-key`) + secretAssignment + **seedWordsPattern**
    `\b[a-z]{3,12}(?:\s+[a-z]{3,12}){11,23}\b` + longHex≥32 + longBase64≥48. This is the SECRET variant
    (DISTINCT from the WAVE-1 services `noInlineMaterial` — capsule==backup scanner; identity's DIFFERS — do
    NOT reuse the service option). Implement as a governed option; structured, byte-identical TS≡Go.
  - **`forbiddenSchemePrefix`** = `hasInlineReferenceScheme` (capsule.go:545): split on first `:`, casefold the
    prefix, reject if in {`data`,`inline`,`literal`}.
- **Conformance ≡ agent**: `schema/capabilities/conformance/capsule.json` (≥ 25 full-request vectors) run by
  BOTH the manifest validator AND `DecodeJSONRequest[capsule.ApplyRequest]`+`Validate()`, asserting agreement.
  Cover: valid reverse-DNS id, valid opaque id, bad id, version edge, every SRI algo + padded/raw + wrong byte
  length (reject), bad state, duplicate id (reject via uniqueBy), absent/null/empty capsules, inline-secret id
  (`"private key"` whitespace-sep ⇒ reject), scheme-prefixed id (reject), dup JSON key, unknown field. The
  REAL entrypoint is the oracle — a wrong expectation fails both planes. NEVER omit a revealing vector.
- **Register** capsule (regenerate `npm run gen:manifests`; the orchestrator updates the registry-size test if
  needed) + evaluator coverage. The agent cap is UNCHANGED.
