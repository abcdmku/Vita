## Objective
The UniFi-style **node overview** (spec FR-008): `buildNodeOverview(client)` calls the agent client
(P2-006) `getHealth()` + `getCapabilities()` and assembles a single typed overview (status, uptime,
healthy flag, the discoverable capability list, and a derived readiness summary). Pure aggregation over
the client's typed results — fail-closed: if the client errors or returns a malformed value, the overview
reports a typed `degraded`/`unreachable` status, never throws.
- Use the P2-006 `AgentClient` (injected — tests pass a mock client; NO network).
- Deterministic given the client's outputs; no I/O of its own.

## User value
The at-a-glance node dashboard data (FR-008) — the first real management-plane read built on the agent
bridge. Everything in the controller UI overview consumes this.

## Non-goals
- No HTTP server, no UI rendering, no real network/agent. Aggregation + typed overview only. Do NOT
  modify the P2-006 client; import it.

## Dependencies
P2-006 (agent client) — merged.

## Acceptance tests
`acceptance_command` — `node-overview.test.ts` (mock `AgentClient`): a healthy agent ⇒ overview with
status `ready`, capabilities listed, healthy true; an agent reporting unhealthy ⇒ `degraded`; a client
that throws/errors ⇒ `unreachable` (fail-closed, no throw); a malformed client result ⇒ degraded/typed
error, not a crash. Orchestrator also runs `npm run typecheck`.

## Performance & security constraints
Deterministic, no I/O/network. Fail-closed (client error/malformed ⇒ typed degraded status, never throw).
Strict TS (no `any`). R2 → reviewer-gated.
