## Objective
Register the two newest capabilities — `identity` (P5-002) and `network` (P7-001) — into `agentd` so
they are discoverable via `GET /operations` and applicable via `POST /apply`, exactly like the first
three (P1-013). Update `agent/cmd/agentd/main.go` to construct both with their production facades and add
them to the registry; add their request decoders to `DefaultRequestDecoders()` in
`agent/transport/server.go` (the same place nodeconfig/time/hostname are registered — without a decoder,
/apply rejects them with "no registered request decoder", the bug fixed earlier).

## User value
Completes the agent's exposed operation set (FR-004/007) — identity + firewall policy become managed
operations the controller can discover + apply.

## Non-goals

  enforcement (those stay in their capabilities / later host contracts).
