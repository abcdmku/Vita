## Objective
Write the six Week-1 ADRs (spec §25 Week 1) capturing the foundational platform decisions, grounded
in the spec's baseline (§5) and source notes (§29). Each ADR is a Markdown file under
`architecture/adr/` with these section headings: **Status**, **Context**, **Decision**,
**Consequences**. Cover:
1. **Debian 13 "trixie"** as the immutable base userland (§5).
2. **Go 1.26** for the narrow privileged system agent (§5, §3.4, §7.1).
3. **Deno 2.8** as the first-party TS runtime + permission broker (§5, §8).
4. **LUKS2 + Btrfs** for encrypted, snapshotting authoritative storage (§5, §10).
5. **RAUC A/B** signed transactional updates with rollback (§5, §10.1, FR-023).
6. **Package isolation** (AppArmor, seccomp, namespaces, cgroup v2; no lifecycle scripts/FFI in TS
   sandboxes) (§5, §7.1, §9.3).

Each ADR should state the decision, the alternatives considered, and the consequences/trade-offs,
referencing the relevant spec sections. Keep them concise and accurate — do not invent versions
beyond the spec baseline.

## User value

undocumented privileged path"), and are a Phase-0 deliverable.
