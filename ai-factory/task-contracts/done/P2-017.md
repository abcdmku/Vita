## Objective
`previewPackageRuntime(entry, lockfile)` (controller/package): the full "what will this package install +
run as" view, COMPOSING the package-platform pieces — `resolveInstallPlan` (P3-001: pinned-closure install
plan + least-privilege capability grants) and `denoSandboxPolicy` (P3-002: granted capabilities → bounded
default-deny Deno permissions). Returns a typed `{ ok: true, installPlan, grants, sandboxPolicy } | { ok:
false, rejections }`. Fail-closed: if resolution rejects (unpinned dep, lifecycle script, out-of-tier
capability) OR the grants can't map to a bounded sandbox, return the typed rejections — never a throw, never
a partial result. The sandbox is derived ONLY from the resolver's granted capabilities (no widening).

## User value
The management-plane "preview install + sandbox" action (FR-009/010): one call shows the pinned install
plan, the least-privilege grants, and the exact bounded Deno sandbox the package would run under — all on
validated inputs, before any fetch/run.

## Non-goals
- No real install/fetch/Deno run, no network, no agent. Compose P3-001 + P3-002 only. Do NOT modify the
  resolver or sandbox source — import + compose them.

## Dependencies
P3-001 (resolveInstallPlan), P3-002 (denoSandboxPolicy), P0-015. Merged.

## Acceptance tests
`acceptance_command` — `package-runtime-preview.test.ts`: a valid entry + pinned lockfile ⇒ install plan +
grants + a correctly-scoped sandbox policy (derived from the grants, never allow-all/run/ffi); an
unpinned/script-bearing/out-of-tier entry ⇒ typed rejections (resolver), no sandbox; a grant the sandbox
cannot bound ⇒ typed rejection; hostile input ⇒ fail-closed (no throw). Assert the sandbox permissions
correspond exactly to the resolved grants. Orchestrator also runs `npm run typecheck`.

## Performance & security constraints
Deterministic, no I/O/network. Fail-closed (compose the two validators; never throw/partial). Sandbox
derived ONLY from resolved grants (no widening; never allow-all/run/ffi). Strict TS (no `any`). R2 →
reviewer-gated (supply-chain + sandbox).
