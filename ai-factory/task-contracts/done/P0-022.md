## Objective
SDK type + fail-closed validator for the unified node desired-state: `NodeConfig` is an object with
OPTIONAL per-capability sections — `storage` (P0-019 StorageLayout), `network` (P8-001 NetworkConfig),
`backup` (P0-020 BackupPolicy), `identity` (P5-001 IdentityConfig). `validateNodeConfig(input)` uses
`safeNormalize`, then validates EACH PRESENT section by DELEGATING to that section's existing SDK
validator (import them; do NOT re-implement), accumulating section-scoped errors (path = section name +
the sub-error path). Returns the typed `NodeConfig` (only the present, validated sections) or the errors.
- **Fail-closed**: an unknown top-level section ⇒ reject (closed section set); a present section that
  fails its validator ⇒ reject with section-scoped paths; an EMPTY config (no sections) ⇒ reject (require
  at least one section — an empty desired-state is almost always a mistake, not "no-op"). Reject duplicate
  JSON keys / hostile input via safeNormalize.

## User value
The single top-level desired-state the controller authors + previews (FR-005/006) — composes the
per-capability models into one validated `NodeConfig`, reusing each section's existing fail-closed validator.

## Non-goals
- No evaluation to a plan (that is the deferred §8.2 evaluator), no agent, no I/O. Compose the existing
  section validators only. Do NOT modify the per-capability models — import them. No shared-index edits.

## Dependencies
P0-019 (storage), P8-001 (network), P0-020 (backup), P5-001 (identity), P0-015 (safeNormalize). All merged.

## Acceptance tests
`acceptance_command` — `node-config-model.test.ts`: a config with several valid sections validates; an
unknown top-level section ⇒ rejected (closed set); a present-but-invalid section ⇒ rejected with
section-scoped error paths (e.g. `network/firewall/allow`); an empty config (no sections) ⇒ rejected;
hostile/partial input ⇒ fail-closed via safeNormalize. Orchestrator also runs `npm run typecheck`.

## Performance & security constraints
Pure/deterministic, no I/O. Fail-closed via safeNormalize + the delegated section validators; closed
section set; reject empty. Strict TS (no `any`). R2 → reviewer-gated.
