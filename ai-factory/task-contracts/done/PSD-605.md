## Objective
Author a **PROPOSED** ADR — `architecture/adr/0012-hostile-capsule-network-gate.md` — that defines the FR-011 (Phase-4 exit, spec §608 + §21) adversarial methodology for the S5 hostile-capsule enforcement gate of ADR-0011 capsule networking. The ADR specifies, as a design document (NO code), exactly how a deliberately-hostile capsule is proven **contained** on a real verity boot by the already-built isolation layers: per-capsule netns (S2, `VITA-CAPSULE-NET-NS … loopback=OK isolation=enforced`), default-deny egress (S3, `VITA-CAPSULE-NET-EGRESS … default=deny`), and host DNAT ingress scoping (S4, `VITA-CAPSULE-NET-INGRESS`). It nails down the threat vectors, the exact MEASURED negative witnesses, and the `VITA-CAPSULE-NET-HOSTILE` marker contract that the later builder slice (P1-062 / `VITA-CAPSULE-NET-LIMITS`) will implement against.

The ADR MUST define these threat vectors and, for each, the exact measured BLOCKED witness:
- **Undeclared egress** to a denied CIDR — capsule attempts an outbound connect to an address outside its declared `egress[]` allowlist → REFUSED at the kernel nft `policy drop` (S3). Witness: connect fails / no packet leaves the netns.
- **Undeclared inbound** listen/connect outside its netns — capsule tries to bind/accept on an interface or reach a peer outside its ephemeral netns (`/run/vita-agent/netns/<unit>/`) → unreachable (no veth/forward composed for an undeclared grant; S4).
- **Lateral probe to a co-resident victim** — ARP / raw-socket probing of a co-resident capsule's `169.254.x` veth → blocked by netns isolation (S2; separate namespaces, no shared link).
- **Host-loopback agentd reach** — capsule attempts to reach the host-loopback agentd control port `:8786` → unreachable from inside the per-capsule netns (loopback is namespace-local, S2).

For each vector the ADR states the **independent host-side measurement** (the P1-055 lesson: the marker reflects the workload's measured reachability + an independent host-side probe of denials, NEVER a synthesized agentd claim), and references the asserted isolation primitives by their real source: `agent/capabilities/capsule/netns.go` + `netns_linux_test` (S2 netns lifecycle) and the S3 default-deny egress nft ruleset builder in the same package, plus `agent/capabilities/network/network.go` validators reused by ADR-0011.

Define the exact marker contract:
```
VITA-CAPSULE-NET-HOSTILE: contained=OK survived=OK status=OK
```
`contained=OK` ⟺ every adversarial action above is measured BLOCKED (host-side probe confirms denial); `survived=OK` ⟺ the node stays up and other capsules keep their declared connectivity (no collateral / no DoS); `status=OK` ⟺ both. Specify the FAILSAFE emission on any breach (e.g. `contained=NOT_OK`/`status=FAILSAFE`) consistent with the existing `VITA-CAPSULE-NET-NS-ERROR … status=FAILSAFE` convention in `execute.go`.

## User value
Pins the Phase-4-exit (FR-011) hostile-network gate as an auditable, MEASURED methodology BEFORE any builder writes the enforcement test — so the gate cannot be gamed (vacuous-acceptance hole, the P1-055/P1-062 lessons) and untrusted capsules only receive network grants once containment is provably held on a real verity boot.
