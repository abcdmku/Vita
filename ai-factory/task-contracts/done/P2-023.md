## Objective
`fetchAuditTrail(transport)` (controller/audit/src/audit-client.ts): consume the agent's NEW `GET /audit`
endpoint (P7-006) through an injected transport function and return a validated, fail-closed result ready
for the existing `summarizeAuditLog` (P2-021). The transport is an injected async function
`(path: string) => Promise<{ status: number; body: unknown }>` (mirroring how controller/api P2-006
abstracts HTTP — do NOT open a real socket; tests inject a fake). Behavior:
- Call `transport("/audit")`. If `status` is 503 (audit unavailable) ⇒ return `{ ok: false, reason:
  "audit_unavailable" }`. Non-200 ⇒ `{ ok: false, reason }`.
- `safeNormalize` the body, then validate the response envelope shape `{ events: [...] }` (reject unknown
  keys/accessors). Validate EVERY event via `validateAuditEvent` (P0-024) — any invalid event ⇒ fail-closed
  typed rejection (no partial trail). Verify the events are strictly monotonic via P0-024 `isMonotonic`;
  if not, STILL return them but with `tampered: true` (never silently reorder — tamper-evidence preserved).
- Return `{ ok: true, events, tampered } | { ok: false, reason, rejections? }`. Never throw (a transport
  that throws/rejects ⇒ `{ ok: false, reason: "transport_error" }`).

## User value
The operator can now retrieve the agent's tamper-evident provenance trail (FR-008/§17) — validated end to
end, with a tamper flag — and feed it straight into the audit viewer (P2-021) / operations report (P2-022).

## Non-goals
- No real HTTP/socket, no network (inject the transport). No summarization here (that's P2-021 — but the
  output must be shaped to feed it). Do NOT modify P0-024 / P2-021 / P2-006 — import/compose them.

## Dependencies

## Acceptance tests
`acceptance_command` — `audit-client.test.ts`: a 200 with a valid monotonic `{events}` ⇒ `ok:true`,
`tampered:false`, events returned; a 503 ⇒ `ok:false reason audit_unavailable`; a non-200 ⇒ `ok:false`;
a body with an invalid event ⇒ typed rejection (no partial trail); a non-monotonic event list ⇒ `ok:true`
but `tampered:true` (not reordered); a transport that throws ⇒ `ok:false reason transport_error`; hostile
body (accessor/unknown key) ⇒ fail-closed with an external-counter probe. Orchestrator runs `npm run typecheck`.

## Performance & security constraints
Deterministic; no real I/O (injected transport). Fail-closed: safeNormalize the body, validate every event
(P0-024), never throw, never reorder to hide non-monotonicity. Strict TS (no `any`). R2 → reviewer-gated.
