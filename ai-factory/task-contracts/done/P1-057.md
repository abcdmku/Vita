## Objective
W6-S1 (ADR-0011 slice 1 — SAFE, no behavior change): wire the capsule manifest's network grants INTO the agentd
execution manifest + VALIDATE them, WITHOUT yet creating any namespace or touching the kernel. Add a `Network` field to
`ExecutionManifest` (`agent/capabilities/capsule/execute.go`), parsed from the on-disk `manifest.json` (the same store
`fileExecutionManifestStore.Load` reads). Validate every grant against an ALLOWLIST that REUSES the proven validators in
`agent/capabilities/network/network.go`: `normalizeCIDR` (canonical, host-bits rejected), the `sourceCoversAll`
wide-open guard (a 0.0.0.0/0 / ::/0 grant rejected unless an explicit unsafe-wide flag), port / `PortAll` rules,
`validInterfaceName`, direction ∈ {ingress,egress}, protocol allowlist. v1: egress destinations = CIDR/IP ONLY
(hostname egress rejected for now — TOCTOU). control-char/metachar rejection on every string (the `capsule.go`/
`services.go` discipline). NO namespace, NO nft, NO RestrictAddressFamilies change yet — a capsule with grants still
runs network-mute (AF_UNIX); this slice only proves the manifest→agentd parse+validate surface in isolation.

Markers: `VITA-CAPSULE-NET-PARSE: id=<id> egress=<n> ingress=<n> status=OK` (grants parsed+validated);
`VITA-CAPSULE-NET-REJECT: reason=<sanitized> status=OK` (an invalid grant — host-bit-smuggled CIDR, wide-open without
the flag, hostname egress, bad port/iface — fails closed). Keep ALL prior markers. Bake a test capsule manifest with a
couple of valid grants + a forced-invalid one.

## User value
The foundation for capsule networking (ADR-0011): the privileged agent ingests + strictly validates a capsule's
declared network grants from the manifest, reusing the node-policy validators — the parse/validate half of FR-011's
"declared network and only that," with zero new reachability or attack surface yet.

## Non-goals
NO netns / veth / nftables / DNAT (S2-S4). NO RestrictAddressFamilies change (capsules stay network-mute this slice).
NO hostname egress (CIDR-only v1). NO ingress enforcement. Just parse + validate, fail-closed.

`storage/capsules/src/capsule.ts`), ADR-0011.
