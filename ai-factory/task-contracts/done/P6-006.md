## Objective
Register the `capsule` capability (P6-004) into `agentd`, exactly like P1-022 wired backup + pdssync.
Construct it with its production facade in `agent/cmd/agentd/main.go` and add it to the registry; add its
request decoder to `DefaultRequestDecoders()` in `agent/transport/server.go`. After this, all TEN
capabilities (nodeconfig, time, hostname, identity, network, storage, update, backup, pdssync, capsule)
are discoverable via `GET /operations`, applicable via `POST /apply`, and readable via `GET /read/{capability}`.

## User value
Completes the agent's exposed operation set — the capsule registry becomes a managed + readable operation
(FR-004/007/012).

## Non-goals

  install/run. No `os/exec`.
