## Objective
Refactor `validateCatalogEntry` (packages/catalog) to use the canonical `safeNormalize` primitive
(`sdk/typescript/src/safe-normalize.ts`, P0-015) for untrusted-input handling, replacing its ad-hoc
intrinsic-safe normalization. Flow: `const n = safeNormalize(input); if (!n.ok) return reject;
/* validate §9.2/§9.3/§13.1 semantics on the trusted plain n.value */`. Remove the duplicated
accessor/exotic/cyclic/method-shadow handling now provided by `safeNormalize`.

**Behavior must be IDENTICAL**: every existing test still passes; the full fail-closed set still holds;
§9.3 trust tiers + §13.1 secrets-as-references + non-empty signatures unchanged.

## User value

shrinks the catalog validator.
