## Objective
Enable **atomic A/B updates** so a deployed node can be updated without reflashing. Author a deterministic
`planRaucBundle()` (`os/x86_64/rauc-bundle.{mjs,conf}`, same pure/no-I/O shape as the other os planners) that
emits: (a) the RAUC **bundle manifest** (`manifest.raucm`: `[update]` compatible string `vita-x86_64`, version;
`[image.rootfs]` filename + the verity root image + its sha256 as an EXTERNAL precondition (unresolved until the
host computes it); slot class `rootfs`), and (b) the **`rauc bundle` command** (inputs → `vita-<version>.raucx`),
modeled like the other planners' command objects (executable `rauc`, args). Signing is SEPARATE (the bundle is
signed at step 4(c) with the owner's RAUC key — model a `Signing` block declare-only, executable=false, like
uki.mjs's signing block; do NOT sign here). Pair it with the A/B slots already in `planImageLayout` (root-a/root-b).

## User value
A node can receive a signed update bundle and atomically switch the inactive slot — the basis for safe remote
updates + rollback. Without it, every change means reflashing.

## Non-goals
- The bundle PLAN + manifest only (+ the unsigned `rauc bundle` command). NOT the signing (owner's RAUC key, step
  4c — declare-only). NOT the on-device RAUC service/install logic yet. NOT delta/casync. Do NOT edit
  build-and-boot.mjs (orchestrator wires execution post-merge). Reuse safeNormalize/canonical-path helpers.

## Dependencies
P1-028 (verity root) merged; `planImageLayout` has the A/B root slots. The verity root image + its roothash are
external preconditions (the host produces them). Read image-layout.mjs + uki.mjs (for the declare-only Signing
block pattern) first.

## Acceptance tests
`acceptance_command` — `rauc-bundle.test.ts`: assert `planRaucBundle()` is byte-deterministic; the manifest carries
the compatible string, version, slot class `rootfs`, the rootfs image filename + sha256-as-external-precondition;
the `rauc bundle` command shape (executable + args, output `.raucx`); the Signing block is declare-only
(executable=false) with NO key material; hostile/partial inputs rejected via safeNormalize. (No `rauc` binary
needed at test time — it's a pure plan.) Orchestrator host-verifies on Borg51: `rauc bundle` produces a bundle +
`rauc info` validates its structure (unsigned/dev-mode).
