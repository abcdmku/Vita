## Objective
Implement the **window-manager POLICY engine as pure TypeScript** (spec §6.2: "WM behavior — layout, focus, workspaces,
animation — is TypeScript policy over the native core's mechanism"). This slice is the **policy half only**, written as
a PURE, deterministic, no-I/O module so it is fully unit-testable HEADLESS (no GPU/compositor needed — the native
mechanism is consumed via the PSD-001 substrate interface as an injected port):
- A `WindowModel` (windows, workspaces, focus stack, geometry) and pure reducers for events: open/close, focus,
  move/resize request, workspace switch, tile/stack layout, minimize/maximize.
- A `layout(model, constraints) -> placements` function: deterministic geometry (tiling + floating), stable ordering,
  same inputs → identical placements (mirror the determinism discipline of the config evaluator).
- Focus policy (focus-follows-intent, focus stack on close), workspace policy (move-to-workspace, switch).
- The engine emits **intents** (reposition texture X to rect R, set focus to W) against the PSD-001 substrate-interface
  port — it NEVER touches a GPU/compositor directly. Window move/resize = a reposition INTENT (no repaint), matching the
  render/composite split.

## User value
WM behavior is owner-customizable TypeScript policy, testable + deterministic, decoupled from the native compositor —
the foundation for the composite TSX shell (PSD-005) and for swapping desktop packages.

## Non-goals
- NO actual compositing/GPU/rendering (PSD-002/003 — VMware-verified). This module only computes placements + emits
  intents against an injected substrate port (a fake port in tests).
- NO TSX shell yet (PSD-005).

## Dependencies
- PSD-001 substrate interface (the port type the policy emits intents against). If PSD-001 is not yet merged, define the
  minimal port type here consistent with PSD-001's `desktop-substrate.ts` and reconcile at merge (keep-both).

## Acceptance
`acceptance_command` passes: the policy reducers + layout are deterministic + fully unit-tested with a FAKE substrate
port (no GPU). Headless-verifiable on Borg51 — NO new boot marker required for this pure-logic slice (its proof is the
unit suite); a later integration slice wires it to the real compositor on the VMware target.

## Security/constraints
- Pure/no-I/O/no-clock/no-random (deterministic). No remote imports; lockfile; no lifecycle scripts.

## Definition of done
- `wm/policy.ts` pure + deterministic; comprehensive unit tests (layout determinism, focus/workspace transitions,
  move=reposition-intent not repaint); typecheck clean. R1 — reviewer + my verification (run the unit suite).
