## Objective
The **MISSING PRODUCER**: convert the P1-011 `Format=directory` rootfs (`vita-debian-trixie-x86_64-root/`) into the
deterministic **ext4 root image(s)** that `planImageLayout` (P1-014, `os/x86_64/image.conf`) AND `planVerity`
(P1-017, `os/x86_64/verity.conf`) ALREADY consume as the unresolved external precondition
`/external/p1-014/converted/vita-root-{a,b}.rootfs.ext4` (+ `vita-recovery.rootfs.ext4`). `planRootfsImage()`
(pure, deterministic — same shape as verity.mjs/image-layout.mjs) emits the byte-reproducible
`mkfs.ext4 -d <rootdir>` (mke2fs) command that builds a read-only ext4 image from the rootfs directory, resolving
that precondition so the verity hash-tree + A/B partition population finally have a real input.
- `os/x86_64/rootfs-image.conf`: pinned ext4 params — fixed filesystem UUID, fixed `hash_seed`, **no journal**
  (`-O ^has_journal`, the root is read-only), fixed block/inode params, `root_owner=0:0` — plus `SOURCE_DATE_EPOCH`
  for reproducible timestamps, the source rootfs directory, and the per-slot OUTPUT image paths that EXACTLY equal
  what `verity.conf` + `image.conf` reference. No eval-time network.
- `os/x86_64/rootfs-image.mjs`: `planRootfsImage()` returning the normalized byte-deterministic conversion plan;
  the source rootfs directory is an UNRESOLVED external precondition (depends on the real P1-011 mkosi build —
  unresolved blocks the conversion); the produced ext4 image is the resolved input for verity/layout. Reuse
  P1-011/P1-014/P1-017's external-precondition, canonical-path (reject `..`/traversal), sentinel-digest-rejection,
  and `safeNormalize` (`../../sdk/typescript/src/safe-normalize.ts`) helpers. Deterministic: same rootfs →
  byte-identical image.

## User value
This is the bridge that makes the dm-verity + A/B layout plans EXECUTABLE: without it the verity hash tree has no
image to format and the root partitions have no content. It turns the boot chain from "smoke (unverified) boots"
into a buildable **verity-verified root** (spec §11) — the tamper-evident integrity guarantee.
