## Objective
WAVE 0a of the [migration-roadmap](../migration-roadmap.md): add the FIRST parity-safe datetime format and
land it WITH its sole consumer, `time.set` (the simplest cap — a single required scalar). One dialect-touching
contract (only ONE in flight — serialize per the roadmap).
- **`rfc3339Instant` StringFormat** (BOTH planes), parity-safe template (P9-009): **Go authoritative** =
  `time.Parse(time.RFC3339, v)` returning no error (this is EXACTLY what `time.Time`'s `UnmarshalJSON` does, so
  it matches the agent's decode). **ANY-OFFSET, not Z-only** — `time.set` accepts any RFC-3339 offset (the
  agent normalizes to UTC later); a Z-only format would be STRICTER than the agent (manifest≢agent). **TS** =
  a STRUCTURED RFC-3339 grammar parser (NOT `Date.parse` — lenient/non-deterministic): full date-time with
  `T`, required seconds, optional fractional seconds, `Z` or `±HH:MM` offset; validate real calendar ranges
  (month 1-12, day-per-month incl. leap years, 24h, leap-second `:60` exactly as Go does — verify Go's
  behavior and match it). Decision MUST equal Go on the corpus.
- **`schema/capabilities/time.json` = the full request** `{ desired: string `rfc3339Instant` }` — note the
  agent's `ApplyRequest` is `{ "desired": time.Time }`, so the request `desired` is the RFC-3339 STRING.
  Match `ApplyRequest.Validate()` EXACTLY: reject the ZERO instant (`IsZero()` — `0001-01-01T00:00:00Z` AND
  an absent/empty `desired`, which Go decodes to the zero time ⇒ reject). **The runtime clock-SKEW check
  (`validateDesiredTime` comparing to the current clock) is in APPLY, NOT in `Validate()` — it is
  runtime/stateful and MUST stay OUT of the manifest** (roadmap trap 6); the conformance tests `Validate()`
  only, so manifest≡agent holds for the static contract. Register it (default registry → +time.set).
  Regenerate (`npm run gen:manifests`).
- **Conformance ≡ agent via the real entrypoint**: `schema/capabilities/conformance/time.json` (≥ 20 vectors)
  + a `datetime-format.test.ts` corpus (≥ 25/format) run by BOTH planes; the Go conformance drives
  `transport.DecodeJSONRequest[time.ApplyRequest]` + `Validate()`. Cover: valid Z, valid +offset, valid
  fractional, the ZERO instant (reject), absent desired (reject), bad month/day, non-leap Feb-29, lenient
  forms `Date.parse` would wrongly accept (reject), Unicode-digit/whitespace traps. NEVER omit a revealing vector.
