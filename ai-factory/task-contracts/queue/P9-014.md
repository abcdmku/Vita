## Objective
Add TWO new `StringFormat`s to the dialect, using the PROVEN parity-safe template (P9-009 ipLiteral:
Go-authoritative stdlib + structured TS canonicalizer + an extensive cross-language conformance corpus that
BOUNDS the parity — the corpus IS the contract). No regex engine.
- **`cidrLiteral`** — an IP network in CIDR notation (`v4` or `v6`). **Go authoritative:** `netip.ParsePrefix`
  + require `prefix == prefix.Masked()` (canonical: no host bits set) and reject a zone (matching how the
  agent network validator treats CIDRs — READ `agent/capabilities/network` first and match it EXACTLY, neither
  stricter nor looser; if the agent allows host bits or a different canonical form, MATCH THAT). **TS:**
  reuse the P9-009 IP parser to parse the address part + an integer-bounded prefix length (0–32 v4 / 0–128 v6)
  + the same masked/canonical check. Decision (accept/reject + the canonical form) MUST equal Go on the corpus.
- **`rfc3339UtcInstant`** — a timestamp the `time.set` cap accepts. **Go authoritative:** `time.Parse(time.RFC3339, v)`
  (or the agent's exact parse — READ `agent/capabilities/time` first; match its accepted shape EXACTLY, incl.
  whether it requires UTC `Z`/offset, fractional seconds, leap-second handling). **TS:** a STRUCTURED RFC-3339
  parser (NOT `Date.parse`, which is lenient + non-deterministic) validating the exact grammar + the same
  range/leap rules. Decision MUST equal Go on the corpus.
- **Conformance corpus** `schema/capabilities/formats/network-formats-conformance.json` (≥ 25 vectors per
  format: canonical, non-canonical-rejected/normalized, boundary prefix lengths, v4/v6, malformed, the
  P9-005-class traps — Unicode digits, leading zeros, overflow, empty) run by BOTH planes; drift fails CI.

## User value
Two more parity-safe formats unblocking the network (CIDR routes/subnets) + time (RFC3339 instant) cap
migrations — extending the dialect with the next two Go-stdlib-authoritative formats.
