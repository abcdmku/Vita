## Objective
Build the ONE canonical primitive every trust-boundary validator (broker, capsule, catalog,
simulation, controller endpoints) should use to convert untrusted `unknown` input into plain, trusted
data — eliminating the re-implemented, repeatedly-buggy normalization each has today. Provide:

`safeNormalize(value: unknown, opts?): { ok: true; value: PlainJson } | { ok: false; reason: string }`

It MUST, using ONLY intrinsic-safe reads (never calling a method off the input), produce a deep,
**frozen** plain clone, or reject (`ok:false`) — and **NEVER throw** (wrap everything; any thrown
error ⇒ `{ ok:false }`). Reject (do not coerce/partially-accept):
- **Accessor properties** — at EVERY level, `Object.getOwnPropertyDescriptor` must be a data
  descriptor (no `get`/`set`); reject objects with any accessor own-property (prevents TOCTOU).
- **Exotic objects** — only plain objects (`Object.getPrototypeOf` is `Object.prototype` or `null`)
  and real arrays (`Array.isArray`); reject `Date`/`Map`/`Set`/`Proxy`/class instances/prototype-
  bearing objects where plain data is expected.
- **Method-shadowed arrays / hostile iterators** — iterate arrays by index only; never `for…of` /
  `.some` / `.map` on the input.
- **Cycles** — track visited; a cycle ⇒ reject.
- **Non-data values** — functions, symbols, non-finite numbers ⇒ reject (bigint per a documented opt).

On success the returned `value` is a frozen deep clone; mutating the original input afterward must not
affect it. Intended usage: `const n = safeNormalize(input); if (!n.ok) return reject(n.reason);
/* operate ONLY on n.value */`.

## User value
This is the security primitive the whole platform's trust boundaries depend on (spec §7.1, §8.2,
§9.3). Centralizing it makes every current and future validator correct-by-construction and auditable
in one place (a §18.5 factory improvement — the recurring boundary bugs all trace to ad-hoc
normalization).

## Non-goals
- No schema/shape validation (that stays in each validator, operating on the normalized plain data).
- No adoption/retrofit of existing validators in THIS contract (a separate follow-up will migrate
  them to import `safeNormalize`).

## Acceptance tests
`acceptance_command`. `sdk/typescript/test/safe-normalize.test.ts` must prove:
1. A valid nested plain object/array normalizes to `ok:true` with a **frozen deep clone**; mutating
   the source afterward does not change the clone.
2. The FULL adversarial set each ⇒ `ok:false`, never throws: `undefined`, non-object, accessor/getter
   property (incl. a flipping getter), `new Date()`/`new Map()`/`Proxy`/class instance, method-
   shadowed array, hostile `Symbol.iterator`, deep cycle, function/symbol value.
3. A getter that would flip across reads is read at most once (no TOCTOU) — proven by a getter that
   counts/throws on 2nd access still yielding a single consistent decision.

## Performance & security constraints
Pure/deterministic, no I/O. NEVER throws. Bounded recursion/visited-set (no unbounded blowup).
