## Objective
P1-034 gives the device a `TransactionPlanChange` ({ added, removed, changed } capability names) from diffing two
evaluator TransactionPlans. This slice renders that change into a deterministic, human-readable summary the operator
can read, and prints it on-device: `VITA-EXPLAIN: lines=<N> status=OK` followed by the rendered lines (each prefixed
so they're grep-able, e.g. `VITA-EXPLAIN| + adds capability <cap>`). Closes the preview loop with a readable "what
will change" — counts (P1-034) + prose (this slice).

Concretely:
- **New UPSTREAM module** `sdk/typescript/src/transaction-plan-explain.ts`: a pure, deterministic
  `explainTransactionPlanChange(change: TransactionPlanChange): readonly string[]` returning a STABLE, SORTED list of
  human-readable lines — e.g. `"+ adds capability <cap>"`, `"- removes capability <cap>"`, `"~ changes capability
  <cap>"`. Deterministic ordering (added, then removed, then changed; each group sorted — match the diff's existing
  sort). Import the `TransactionPlanChange` type from `./transaction-plan-diff.ts`. No I/O. If the change is empty,
  return a single `"no changes"` line.
- **Test** `sdk/typescript/test/transaction-plan-explain.test.ts`: determinism (same change → identical lines across
  repeats); correctness (known added/removed/changed → exact expected lines, correctly ordered); empty → `["no
  changes"]`; and that it does not throw on a frozen/edge `TransactionPlanChange`.
- **Vendor** `transaction-plan-explain.ts` into `os/x86_64/ts-overlay/usr/lib/vita/ts/vita/` (byte-identical to
  upstream except a `// Vendored from …` header + import-path adjustment to `./transaction-plan-diff.ts`).
- **`main.ts`**: after the existing `VITA-PREVIEW` step, render the SAME `TransactionPlanChange` via
  `explainTransactionPlanChange` and print `VITA-EXPLAIN: lines=<N> status=OK` + each line as `VITA-EXPLAIN| <line>`.
  Keep ALL existing markers (VITA-TS/EVAL/EVAL-REJECT/PREVIEW/PREVIEW-NOOP). Pure; no FS/network.

## User value
The operator gets a readable, deterministic description of a pending config change on-device — the human-facing half
of the preview, built on the same evaluator output, with zero new privilege.

## Non-goals
NO apply/agentd. NO PDS. NO network. NO rich i18n/templating (plain ASCII lines). Vendor exact source. Do NOT touch
the evaluator/diff/safe-normalize/service or the apply paths beyond adding the explain step + marker in main.ts.

lines=.. status=OK` + the `VITA-EXPLAIN|` lines on the serial; `deno check` clean.
