## Objective
SDK type + fail-closed validator for the installed-capsule registry (spec §13/FR-012) — the TS counterpart
to the Go agent capsule capability (P6-004), so the controller can validate + diff capsule registries it
reads via `/read`. `CapsuleEntry` = id + version + integrity (SRI) + state ("installed"|"disabled");
`CapsuleRegistry` = a list of entries. `validateCapsuleRegistry(input)` uses `safeNormalize`, then
validates on the trusted plain value.
- **Validate fail-closed**: capsule id well-formed (reverse-DNS NSID or opaque id); version non-empty;
  integrity a real SRI (`sha(256|384|512)-<base64>`); state from the closed set; reject DUPLICATE capsule
  ids; reject embedded capsule bytes (reference + integrity only, §13.1). Absent required field ⇒ reject.

## User value
The typed contract the controller uses to validate the capsule registry read from the agent and to
preview capsule changes (FR-012, §13) — pinned, integrity-verified, deduplicated.

## Non-goals
- No capsule install/run/network/crypto, no agent. Types + pure validator only. No shared-index edits.

## Dependencies
P0-015 (safeNormalize). Merged. (Mirror the P6-004 Go registry shape.)

## Acceptance tests

SRI/state rejected with paths; duplicate capsule ids rejected; embedded capsule bytes rejected (§13.1);
