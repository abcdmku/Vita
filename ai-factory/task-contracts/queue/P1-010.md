## Objective
Third transactional capability: `agent/capabilities/hostname/`. A `TxCapability` named `hostname.set`:
`Handle` reads the current hostname; `Apply(ctx, req)` validates a desired hostname, sets it via a
narrow injected facade, and returns an `Undo` restoring the prior; rollback proven through
`transaction.Apply`.
- Linux impl (`set_linux.go`, `//go:build linux`): set the kernel hostname via the `sethostname`
  syscall (golang.org/x/sys/unix) AND atomically write `/etc/hostname` (temp+rename, the single commit
  point — no error path after the rename, per the P1-007 lesson). **No `os/exec`/hostnamectl shell.**
  `set_stub.go` (`//go:build !linux`) returns unsupported. Tests inject an in-memory facade.
- **Validate the request as a strict RFC-1123 DNS label**: 1–63 chars, lowercase `[a-z0-9-]`, no
  leading/trailing `-`, not all-numeric. Reject anything else fail-closed. Request data never becomes a
  path/command.

## User value
Hostname is foundational for network identity/discovery (§12). Further generalizes the transactional
capability pattern.

## Reviewer revision (round 2 — BLOCKING, from P1-010.review.md)
1) **Commit-point ordering** (the P1-007 lesson): the round-1 code called `Sethostname` BEFORE the
   `/etc/hostname` rename — if the rename fails after `Sethostname` succeeds, the live kernel hostname
   is mutated with no Undo. Restructure to a SINGLE commit point with NO untracked mutation on failure:
   capture prior hostname + prior `/etc/hostname` first; sequence the irreversible kernel `sethostname`
   and the atomic file write so that success ⇒ a working restoring `Undo`, and ANY failure ⇒ live system
   unchanged (or fully restored before returning the error). No fallible step after the commit point.
2) Use `agent/internal/sysdeps.SetHostname` (real vendored `golang.org/x/sys/unix`), NOT stdlib `syscall`.
3) Add the **partial-failure regression**: inject a failure at/after the apply point via the in-memory
   facade and assert NO untracked hostname mutation (either fully applied + undoable, or unchanged).
