## Objective
W6-S2 (ADR-0011 slice 2 — SAFE isolation, NO external reachability): for a capsule whose validated manifest declares
network grants (P1-057), agentd creates a PER-CAPSULE ephemeral Linux network namespace + joins the hardened transient
unit to it, with ONLY loopback inside (no veth/NAT/nft yet — that's S3). Proves the netns lifecycle + teardown + that
the hardened profile still holds. A network-granted capsule's `RestrictAddressFamilies` widens to AF_INET/AF_INET6/
AF_NETLINK (needed to open sockets at all), but with NO route off the namespace → the capsule can bind/connect only on
its OWN loopback; it CANNOT reach the host or any external network. Capsules WITHOUT grants are unchanged (AF_UNIX,
no namespace).

Concretely (`agent/capabilities/capsule/netns.go` new + `execute.go` wiring):
- agentd creates an ephemeral netns under `/run/vita-agent/netns/<unit>/` (agentd-owned, tmpfs); the transient unit
  joins it via `NetworkNamespacePath=` (systemd) or `PrivateNetwork` + a setup, composed from the VALIDATED manifest
  only. Loopback (`lo`) up inside; NO veth/host bridge.
- Conditional `RestrictAddressFamilies` (AF_INET/INET6/NETLINK) ONLY for granted capsules; non-granted keep AF_UNIX.
  ALL other hardening knobs UNCHANGED (DynamicUser, empty caps, NoNewPrivileges, ProtectSystem=strict, seccomp, cgroup).
- `TeardownNetns` on undo: tear down the namespace (the transaction-engine undo, like volumes). Ephemeral, no leak.
- The baked test capsule (with grants) binds+connects on its OWN loopback (succeeds) and ATTEMPTS to reach an external
  addr (must FAIL — no route). The marker is MEASURED from the workload's real result + an agentd-side check that the
  capsule has its OWN netns (cannot see host interfaces).
Markers: `VITA-CAPSULE-NET-NS: id=<id> netns=<name> loopback=OK isolation=enforced status=OK`;
`VITA-CAPSULE-NET-NS-REJECT: reason=<specific> status=OK`; `…-ERROR: status=FAILSAFE`. Keep ALL prior markers (incl.
NET-PARSE). Apply the lessons: MEASURED marker (no synthesized OK — gate on the workload's real loopback success +
external-FAIL), and a long-running test workload so the unit holds active (res=success) for a clean health read.

## User value
Per-capsule network isolation — each network-granted capsule gets its OWN namespace (its own loopback, cannot see the
host or other capsules' networking), the kernel-enforced foundation for default-deny egress/ingress (S3/S4). Still NO
external reachability (safe).

## Non-goals
NO veth/NAT/nftables/DNAT (S3/S4). NO external reachability (loopback-only). NO ingress. Non-granted capsules unchanged.
agentd composes the netns ONLY from the validated manifest (never raw runtime text).
