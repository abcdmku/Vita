## Objective
Headless, deterministic view-model for **Files operations — rename/move/copy/trash/restore/new-folder**, built ONLY on `@vita/desktop-sdk` public ports (the files capability port (PSD-007)) — injected ports, NO
platform internals, NO DOM (pure logic the rendered desktop binds to). Code: `ui_kits/desktop/viewmodels/files-ops.ts`; test:
`sdk/typescript/test/ui-kits/FilesOps.test.ts`. Build against CURRENT main (wave-1+2 merged). Import the SDK as
`ui_kits/desktop/package.ts` does; ONLY public exports. If a needed port is missing, define a MINIMAL injected port
interface (typed, fail-closed) fully testable against a fake now.
- A files-clipboard (cut/copy target set + mode), pending-op queue, and trash model. Actions: rename(entry,name), move(entries,dest), copy/cut + paste(dest), trash(entries), restoreFromTrash(ids), newFolder(dest,name), duplicate(entry). All mutations go through the files port; deterministic name-collision handling (append a numeric suffix); fail-closed without the files grant.

## User value
Extends the Vita desktop BEYOND the imported mockups with real, tested Files operations — rename/move/copy/trash/restore/new-folder behavior on the SDK — a complete desktop OS.

## Non-goals
- NO DOM/CSS/CEF, NO platform internals, NO new visual design. Consume ports; don't reimplement them.

## Acceptance
`acceptance_command` passes: deterministic tests cover the described state transitions + fail-closed paths against fakes; typecheck clean.

## Security/constraints
- Injected ports only (no ambient I/O); capability-mediated fail-closed; pure/deterministic. No remote imports; lockfile; no lifecycle scripts.

## Definition of done
- `ui_kits/desktop/viewmodels/files-ops.ts` + `sdk/typescript/test/ui-kits/FilesOps.test.ts`, deterministic, typecheck clean. R1.
