## Objective
The integration keystone for the desktop pod: a single **host-context** module that composes every backend port into one concrete `DesktopHost` and drives the real flagship package through the SDK loader's known-good-fallback path. Headless — no CEF channel.
- Add `sdk/typescript/src/desktop-sdk/host-bootstrap.ts` exporting `createDesktopHost(deps)` (and a `DesktopHostBootstrapDeps` type) that wires the backend ports built by the dependency slices into one object satisfying the `DesktopHost` interface (`sdk/typescript/src/desktop-sdk/ui-package.ts:123`): shell engine (`registerComponent`/`previewShell`/`applyShell`/`rollbackShell`/`currentShell`, PSD-351), apps + launcher (`launchApp`/`stopApp`/`emitLauncherIntent`, PSD-348), notifications + tray (`postNotification`/`registerTrayItem`, PSD-350), files (`requestFile` → agentd, PSD-344), settings (`readSetting`/`previewSetting`/`applySetting`, PSD-345), and theme (`readTheme`, PSD-346). The agentd client is an **injected dependency** (no ambient I/O); in tests it is faked.
- Provide `mountDesktop(deps, options?)` that constructs the host via `createDesktopHost`, then runs the real package through `loadUiPackage(desktopUiPackage, host, options)` (`sdk/typescript/src/desktop-sdk/loader.ts:338`) so the production known-good fail-closed path is exercised — NOT a hand-built degraded host.
- Consume ONLY public SDK exports + the dependency-slice backend factories. Import the package exactly as production does (`ui_kits/desktop/package.ts:1`). No DOM/CEF, no platform internals beyond the injected agentd/capsule client.
- Code under `sdk/typescript/src/desktop-sdk/host-bootstrap.ts`; export it from `sdk/typescript/src/desktop-sdk/index.ts`. Tests under `sdk/typescript/test/ui-kits/host-bootstrap.test.ts`.

## User value
Proves that one `desktopUiPackage.mount(host)` call wires every desktop action (screens, shell, app launch, notification, tray, files, settings, theme) to a real backend on the public host contract — the single seam the CEF channel will later attach to. Until this exists the backends are islands; this is the slice that makes the desktop boot as a whole, headless, before any GPU/CEF work.

## Non-goals
- NO CEF channel, OSR host, DOM, CSS, or rendering. NO real socket/file I/O — the agentd/capsule client is injected and faked in test.
- Do NOT re-implement the backend ports (consume the PSD-344/345/346/348/350/351 factories) or fork/weaken the loader's fail-closed path. NO new visual design.

## Acceptance
`acceptance_command` passes. Deterministic integration tests (Node test runner, `--experimental-strip-types`) against in-memory fakes for the agentd/capsule client cover, at minimum:
- `mountDesktop` with all backends healthy succeeds: the package registers all 8 screens (`desktopScreenSurfaces`), applies the `desktop` shell config, launches `vita.desktop.flagship`, posts the `desktop.notifications` notification, and registers the `desktop.status` tray item — the load result is `ok` with `loaded.source === "requested"` (the REAL package, not the fallback).
- Fail-closed: when an injected backend throws on mount (e.g. shell apply or app launch fails), the loader recovers to the known-good fallback (`loaded.source === "fallback"`, `recoveredFrom` set) and the host is left consistent (no partial app launched / shell rolled back).
- Clean teardown: `loader.unmount()` (or the returned instance's `unmount`) tears down with no error — app stopped, shell rolled back.
- Capability mediation is real: a request the manifest does not grant fails closed via the scoped host (e.g. `MISSING_CAPABILITY`), proving `createDesktopHostForPackage` scoping is in the path.
Typecheck clean; pure/deterministic (no wall-clock, no network, byte-stable assertions). An empty branch fails (the exact test path does not exist).

## Security/constraints
- Injected ports only (no ambient I/O); the agentd/capsule client is a constructor dependency. Capability-mediated and fail-closed throughout — every action flows through the scoped per-package host. No remote imports; lockfile mandatory; no package lifecycle scripts; no FFI/native addons. Deterministic: same fakes → byte-identical observable behavior.
