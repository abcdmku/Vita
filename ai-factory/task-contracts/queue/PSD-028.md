## Objective
Headless, deterministic **view-model** for the flagship desktop's `index` screen (`ui_kits/desktop/index.html` / index.html),
built ONLY on `@vita/desktop-sdk` public ports (the app launch/lifecycle port) — injected ports, NO platform internals, NO DOM/rendering (the view-model
is the pure interaction logic the rendered design binds to later).
- State: ordered dock items (pinned apps from the design: terminal/code/folder/mail/globe/settings), running indicator + focused app derived from the launch/lifecycle port. Actions: launchOrFocus(appId), isRunning(appId). Deterministic; fail-closed without the launch grant. Name the test file index-dock.test.ts so it matches index*.
- Put the code under `ui_kits/desktop/viewmodels/index.ts` and tests under `sdk/typescript/test/ui-kits/index.test.ts`.
- Import the SDK exactly as `ui_kits/desktop/package.ts` does; use ONLY public exports.

## User value
Turns the static `index` mockup into real, testable desktop behavior on the SDK — the logic the CEF-rendered HTML hydrates against.

## Non-goals
- NO DOM/CSS/rendering/CEF. NO platform internals. NO new visual design (the HTML is the design of record). Don't re-implement SDK ports — consume them.

## Acceptance
`acceptance_command` passes: deterministic unit tests cover the state transitions + fail-closed paths described above against fake SDK ports; typecheck clean. Pure, headless.

## Security/constraints
- Injected ports only (no ambient I/O); capability-mediated, fail-closed; pure/deterministic. No remote imports; lockfile; no lifecycle scripts.

## Definition of done
- `ui_kits/desktop/viewmodels/index.ts` + `sdk/typescript/test/ui-kits/index.test.ts`, deterministic, typecheck clean. R1.
