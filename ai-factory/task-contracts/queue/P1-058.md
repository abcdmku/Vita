## Objective
W5-S8 (ADR-0012 slice 1, ACCEPTED): run a `wasm-service` capsule — a baked first-party `wasm32-wasip1` module — via a
PINNED wasmtime as the workload inside the BYTE-FOR-BYTE ADR-0009 hardened transient unit. NO `RootDirectory=` (a host
process under ProtectSystem=strict reading one staged `.wasm`). Add a third `packageClass` branch + `composeWasmTransientUnit`
+ `wasmtimeArgv` to `execute.go` (modeled on `composeTypeScriptTransientUnit`/`denoArgv`); extend `ExecutionRuntime` to a
3-way mutually-exclusive union (typescript XOR oci XOR wasm) with a `WasmExecution{module}` arm validated like
`TypeScriptExecution` (fixed `component.wasm`). Hardening = `hardenedTransientUnitProperties(manifest, false)` (no Deno
pkey) + cgroup caps + StateDirectory. `ExecStart=/usr/lib/vita/bin/wasmtime run <WASI flags> /usr/lib/vita/capsules/<id>/
component.wasm`. WASI capabilities default-deny, derived ONLY from the validated manifest (v1: no preopen unless a volume
is declared — that's S2; empty env + a fixed allowlist; WASI sockets OFF). Executor path pinned-absolute; module a fixed
literal; manifest-only composition (runtime proposes only {id,version,integrity}).

STAGE wasmtime like the pinned Deno/crun (download-at-build + sha256-verify; NOT committed): the ORCHESTRATOR provides
the pin (wasmtime 36-LTS version + URL + sha256, resolved + verified at dispatch, same as the crun 1.21 pin); the worker
adds a `Wasmtime` block to a conf (mirror ts-image.conf's Deno block) + a fetch+verify+extract-member+stage step (mirror
ts-image.mjs) → `/usr/lib/vita/bin/wasmtime` (0755). Offline override env `VITA_WASMTIME_TARBALL`.

Markers (MEASURED — gated on real agent-reported health, the P1-055 lesson — clone the OCI emitter):
`VITA-CAPSULE-WASM-EXECUTED: id=<id> unit=<unit> uid=<dynuid> runtime=wasmtime health=OK status=OK`;
`VITA-CAPSULE-WASM-EXECUTE-REJECT: reason=<specific> status=OK`; `VITA-CAPSULE-WASM-EXECUTE-ERROR: status=FAILSAFE`.
Bake `local.wasm.capsule` (a tiny first-party wasm32-wasip1 module: prints a sentinel + a lifecycle-healthy hold) + a
forced-invalid. Keep ALL prior markers.

## User value
The node runs WebAssembly capsules — the most CONTAINED runtime class (sandboxed bytecode: systemd jail + WASI
capability boundary + WASM memory-safety = three layers), completing the spec's WASM-component-execution deliverable.
