## Objective
Add a read-only `GET /state` endpoint to the agent transport that returns the CURRENT config of EVERY
registered capability in one response — a deterministic aggregate of what `GET /read/{capability}` returns
per-capability, so the controller node-state reader can fetch the whole node in one call instead of 11
round-trips. Response shape: `{ "capabilities": { "<name>": <current-config-json>, ... } }` with the
capability names in SORTED order (byte-stable), each value the SAME canonical bytes that
`/read/{capability}` returns for that capability. A capability whose read fails surfaces a typed
per-capability error entry (`{ "<name>": { "error": "<reason>" } }`) WITHOUT failing the whole response or
leaking internals — fail-closed per capability. Loopback-only, GET-only (reject other methods), no
mutation.

## User value
One-call whole-node state for the dashboard (FR-004/008) — fewer round-trips, a byte-stable snapshot of
every capability's current config.

## Non-goals
- No new capability, no mutation, no `/apply` change. Read-aggregate only. No `os/exec`. Do NOT change the
  per-capability `/read/{capability}` behavior — reuse the same read path so bytes match exactly.

## Dependencies
P7-003 (all 11 caps registered + the existing /read path). Merged. Reuse the existing registry + Handle/read path.

## Acceptance tests
`acceptance_command` (go test in golang:1.26) + orchestrator `go vet`. Cover: `GET /state` returns all
registered capabilities (sorted) with each value byte-identical to that capability's `/read/{capability}`
response; a capability whose read errors yields a typed per-capability error entry while the others still
return (whole response still 200, fail-closed, no internal leak); a non-GET method is rejected; the
endpoint performs NO mutation. Use the existing httptest harness + injected facades.

## Performance & security constraints
TCB (transport). Loopback-only, GET-only, no mutation. Deterministic + byte-stable (sorted names, canonical
per-cap bytes identical to /read). Per-capability fail-closed (one bad read does not 500 the node or leak
internals). `go vet` clean. R3 → reviewer-gated.
