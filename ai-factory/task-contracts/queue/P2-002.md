## Objective
Build the **pure decision core** of the permission broker (spec §7.1 policy decision engine, §11
per-app data/network capabilities, §12.2 default-deny network policy). This is R2 — independently
reviewed before merge. Provide:
- Typed `CapabilityRequest` and `CapabilityGrant` models for **data** access (class + mode
  read-only/read-write, scoped) and **network** access (ingress/egress, default-deny), reusing the
  package-contract declarations from P1-001 (`sdk/manifests`) where natural (import, don't duplicate).
- `decideGrants(request: CapabilityRequest, policy: BrokerPolicy): GrantDecision` — a **pure,
  deterministic, default-deny, least-privilege** function: grant only what the policy explicitly
  allows AND the package declared; deny by default; never escalate beyond the destination policy
  (spec §13.1 "import never grants more permissions than the destination policy permits"). Return a
  typed decision listing granted vs denied capabilities + reasons. Fail-closed and **never throw** on
  malformed/`unknown`/cyclic input (per AGENTS.md) — unknown/ambiguous ⇒ deny.

## User value
The broker is a trusted-computing-base component: it is the choke point that keeps untrusted
workloads least-privileged (spec §7.1, §11, §12.2). Its decision logic must be conservative and
auditable.

## Non-goals
- No enforcement/runtime wiring, no Deno integration, no sockets — the **decision function only**.
- No identity/auth; assume a resolved policy is passed in.

## Dependencies
P1-001 (package contract declarations).

## Acceptance tests
`acceptance_command`. `runtime/permission-broker/test/decide.test.ts` must prove:
1. A request for a capability the policy allows AND the package declared is granted; one the policy
   forbids (or the package didn't declare) is denied with a reason.
2. **Default-deny:** an undeclared/unknown capability is denied (not silently allowed).
3. Import/escalation guard: a request exceeding the destination policy is denied (no escalation).
4. Fail-closed: malformed/cyclic/`unknown` input yields all-denied, never throws.

## Performance & security constraints
Pure/deterministic, no I/O. **Default-deny, least-privilege, fail-closed, never-throw.** No new
privileged surface. R2 → reviewer-gated.
