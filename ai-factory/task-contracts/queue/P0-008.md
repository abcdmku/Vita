## Objective
Provide a reusable **reproducibility gate** for the plan pipeline (spec §16 reproducible-build
evidence, §8.4 "same inputs must produce the same plan", §20.1 "reproducible-build comparison").
Implement `assertDeterministic<I, O>(fn: (i: I) => O, input: I, opts?: { runs?: number }): void` that
runs `fn` N times (default 50), canonically serializes each result, and throws a descriptive error
if any run differs from the first. Add `isDeterministic(...)` returning a boolean for non-throwing
use. Pure, no I/O.

## User value
Determinism is what makes plans signable, diffable, and migratable. A reusable gate lets every later
SDK module prove byte-stability cheaply, and is the offline analogue of the reproducible-build lane.

## Non-goals
- No dependency lockfile / Nix pinning (that needs the build toolchain — separate, deferred task).
- No I/O, clock, or randomness.

## Dependencies
P0-001 (`normalize`, `planHash`) — used by the test to demonstrate the gate on the real pipeline.

## Acceptance tests
`acceptance_command`. `sdk/typescript/test/repro.test.ts` must prove:
1. `assertDeterministic` passes for `normalize` over a representative `DesiredState`.
2. It throws (with a clear message) for a deliberately non-deterministic function (e.g. one that
   returns a different value per call).
3. `isDeterministic` returns true/false correspondingly.

## Performance & security constraints
Pure/deterministic, no I/O. Node built-ins only.
