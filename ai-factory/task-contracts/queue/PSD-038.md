## Objective
Headless, deterministic view-model for **Spotlight / global search across apps+files+commands+settings**, built ONLY on `@vita/desktop-sdk` public ports (the launcher/command + files ports) — injected ports, NO
platform internals, NO DOM (pure logic the rendered desktop binds to). Code: `ui_kits/desktop/viewmodels/search.ts`; test:
`sdk/typescript/test/ui-kits/Search.test.ts`. Build against CURRENT main (wave-1+2 merged). Import the SDK as
`ui_kits/desktop/package.ts` does; ONLY public exports. If a needed port is missing, define a MINIMAL injected port
interface (typed, fail-closed) fully testable against a fake now.
- Aggregate apps, files, commands, and settings into ONE ranked result list. State: query, grouped+ranked results, selection. Actions: setQuery(q) -> deterministic fuzzy ranking across sources, moveSelection(±1), execute(result) -> launch/run/open via the right port. Per-source fail-closed (a missing grant degrades that source, never crashes the search).

## User value
Extends the Vita desktop BEYOND the imported mockups with real, tested Spotlight / global search across apps+files+commands+settings behavior on the SDK — a complete desktop OS.

## Non-goals
- NO DOM/CSS/CEF, NO platform internals, NO new visual design. Consume ports; don't reimplement them.

## Acceptance
`acceptance_command` passes: deterministic tests cover the described state transitions + fail-closed paths against fakes; typecheck clean.

## Security/constraints
- Injected ports only (no ambient I/O); capability-mediated fail-closed; pure/deterministic. No remote imports; lockfile; no lifecycle scripts.

## Definition of done
- `ui_kits/desktop/viewmodels/search.ts` + `sdk/typescript/test/ui-kits/Search.test.ts`, deterministic, typecheck clean. R1.
