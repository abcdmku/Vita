## Objective
Close the **final trusted-boot gap**: today `planUKI` (P1-012) emits ONE UKI whose cmdline is label-based
(`os/x86_64/uki.conf` / `uki.mjs:24`: `root=LABEL=vita-debian-trixie-x86_64-root ro systemd.volatile=no quiet`),
so the assembled UKI boots the UNVERIFIED root, NOT the verity-mapped device — the dm-verity root hash that
`planVerity` (P1-017) captures is never bound into the boot. Make `planUKI` emit **per-slot verity-bearing UKIs**:
each root slot's UKI carries THAT slot's verity cmdline `root=/dev/mapper/vita-root-{a,b}-verity
roothash=<UNRESOLVED> ro systemd.volatile=no quiet` — identical (modulo the roothash) to `planVerity`'s
`slot.uki.cmdline.template` for the same slot. The root hash is an **UNRESOLVED external precondition** (runtime
`veritysetup` output; the build substitutes it before ukify) — unresolved blocks the UKI assembly.
- `os/x86_64/uki.conf`: per-slot UKI entries (root-a, root-b) — each pins its verity device + cmdline-options +
  the UKI output path; the roothash is a sentinel/unresolved placeholder, never a fake value. SOURCE_DATE_EPOCH
  kept. No eval-time network.
- `os/x86_64/uki.mjs`: `planUKI()` returns the per-slot verity UKI plan; each slot's `ukify build` command carries
  `--cmdline "root=<verity device> roothash=<placeholder> …"`. The per-slot cmdline MUST equal `planVerity`'s
  per-slot cmdline template EXACTLY (assert cross-plan coherence — no drift; reference the real verity.conf/
  verity.mjs values, never a private copy — trap-8 self-reference). Reuse P1-012/P1-014/P1-017's
  external-precondition, canonical-path, sentinel-rejection, and `safeNormalize` helpers.

## User value
This is what makes the boot tamper-evident (spec §11): the kernel verifies every root block against the signed
root hash. Without it the UKI boots an unverified root and dm-verity is decorative.

## Non-goals
- No real `ukify` run (orchestrator executes it on the host). Plan + determinism test only. No Secure Boot signing
  (separate, needs owner keys §16). Do NOT modify verity.mjs/image-layout.mjs beyond REFERENCING their values; do
  NOT edit `build-and-boot.mjs` (the orchestrator wires step 3 to build per-slot verity UKIs post-merge).
