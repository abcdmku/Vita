## Objective
Read the persistent PDS sync-state THROUGH agentd over the unix socket — keeping agentd the single owner of
persistent storage (the runtime does NOT touch /var directly). agentd already has a transactional `pds.sync-state`
capability (`agent/capabilities/pdssync/pdssync.go`, persists `pds-sync-state.json`) with a read handler. At boot,
after `VITA-APPLY`, `main.ts` reads it via the vendored agent-client (`getState("pds.sync-state")` / `GET
/read/pds.sync-state`) and prints `VITA-PDS: repo=<did|none> cursor=<n> head=<cid|none> status=OK` (fields per what
the handler returns), or `VITA-PDS-ERROR: status=FAILSAFE` on any failure (never crash the oneshot).

Concretely:
- **Find the read shape.** Read `agent/capabilities/pdssync/pdssync.go` + agentd's `/read/{cap}` route to learn the
  `pds.sync-state` read payload (repo/cursor/head or similar). Use the EXISTING read endpoint — NO agentd change
  expected (it already serves reads). Do NOT add a direct `/var` grant to the runtime.
- **New module** `os/x86_64/ts-overlay/usr/lib/vita/ts/vita/pds-read.ts`: a small helper that uses the vendored
  `agent-client.ts` (S2) over the read-only unix transport to fetch `pds.sync-state` and format the `VITA-PDS` fields.
  Validate the (untrusted) agentd response via `safeNormalize` + the existing validators; fail-closed to a safe
  result on malformed/missing.
- **`main.ts`**: after `VITA-APPLY`, call the pds-read helper and print `VITA-PDS` (+ `VITA-PDS-ERROR: FAILSAFE`).
  Keep ALL prior markers (TS/EVAL/EVAL-REJECT/PREVIEW/PREVIEW-NOOP/EXPLAIN/CONNECT/STATE/APPLY). Read-only; AF_UNIX
  only; no new privilege.

## User value
The node can read its own persistent identity/sync state on-device, through the privileged boundary — the read half
of the PDS, the basis for the write half (S5) and federation later. Confirms the persistent store is reachable
without giving the unprivileged runtime any direct disk access.

## Non-goals
NO PDS WRITE (that's S5, via apply). NO direct `/var`/StateDirectory grant to the runtime. NO network. NO new agentd
capability (pds.sync-state exists). Read-only.

Untrusted-response parsing via safeNormalize. Fail-closed marker. No keys. R2 (read over an existing sensitive
capability) → reviewer-gated.
