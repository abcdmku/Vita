## Objective
Build the missing **host-context counterpart** of `createSurfaceHost` (`ui_kits/desktop/runtime/host-bridge.ts:180`):
a pure **request router** that takes a `SurfaceHostRequest { method, args }` — the EXACT wire shape `host-bridge.ts`
emits at `buildRequest` (`host-bridge.ts:472`, `args` already snapshotted to frozen plain JSON) — validates the
method and arity, snapshots the `args` to plain JSON itself (defense-in-depth; the router does not trust the caller),
routes to an **injected backend-port object**, and returns the `{ ok: true, value }` | `{ ok: false, error }` envelope
that `host-bridge.ts` expects to parse back (the shape consumed by `normalizeHostResult` at `host-bridge.ts:621` and the
shell/theme/snapshot decoders). This is the seam every later real backend (controller, files capability, settings store)
plugs into; for this slice it ships in-memory fakes for every port so it is fully headless-testable.

- Module: `sdk/typescript/src/desktop-sdk/surface-host-router.ts` (a public SDK export — add to
  `sdk/typescript/src/desktop-sdk/index.ts`). Test: `sdk/typescript/test/ui-kits/surface-host-router.test.ts`.
- The router covers ALL 15 methods of the `SurfaceHostMethod` union (`host-bridge.ts:44`):
  `registerComponent`, `previewShell`, `applyShell`, `rollbackShell`, `currentShell`, `launchApp`, `stopApp`,
  `postNotification`, `registerTrayItem`, `requestFile`, `readSetting`, `previewSetting`, `applySetting`,
  `emitLauncherIntent`, `readTheme`. Each method has a fixed arity (the `[definition]`/`[input]`/`[]` arrays passed in
  the `forward*` call sites of `host-bridge.ts`); validate it.
- Accept an injected backend object whose member functions mirror the `Surface*HostPorts` groupings already declared in
  `host-bridge.ts:81-93` (`SurfaceShellHostPorts`, `SurfaceAppHostPorts`, `SurfaceNotificationHostPorts`,
  `SurfaceFilesHostPorts`, `SurfaceSettingsHostPorts`, `SurfaceLauncherHostPorts`, `SurfaceThemeHostPorts`). Reuse those
  exported types — do NOT redefine them.
- Fail-closed envelopes for: unknown `method`, wrong `args` arity, and non-JSON / cyclic args. Return a stable
  `{ ok: false, error: { code, message, path } }` with a deterministic `code` (e.g. `HOST_ROUTER_UNKNOWN_METHOD`,
  `HOST_ROUTER_BAD_ARITY`, `HOST_ROUTER_NON_JSON`) so callers can branch on it. The `error` shape MUST satisfy the
  `isHostError` guard (`host-bridge.ts:1064`: `{ code: string, message: string, path: string }`).
- Ship in-memory fakes for every port (a `createInMemorySurfaceBackend()` factory) so the router is testable with zero
  platform internals: deterministic shell layouts, a tiny in-memory FS for `requestFile`, an in-memory settings/theme
  store, app launch/stop returning well-formed `DesktopAppLaunch`/`DesktopAppStop`.
- Import the SDK exactly as `ui_kits/desktop/runtime/host-bridge.ts` does; use ONLY public exports. No DOM, no I/O, no
  CEF, no platform internals.

## User value
Closes the round trip: today `createSurfaceHost` emits requests into a transport that nothing on the host side answers.
This router is the host half — a pure, injectable dispatcher every real backend plugs into — and the fakes make the
whole surface call path end-to-end testable headlessly, off-device.

## Non-goals
- NO real backend (no controller IPC, no real filesystem, no settings persistence) — only the dispatcher + in-memory
  fakes. NO DOM/CSS/CEF/rendering. Do NOT modify `host-bridge.ts` (the client wire shape is the contract of record) — if
  a shared type is needed, re-export it; do not fork it. Do NOT re-implement the JSON snapshot logic's public behavior
  contract differently from `host-bridge.ts` (fail-closed on non-JSON/cyclic/non-finite).

## Acceptance
`acceptance_command` passes. The deterministic test `sdk/typescript/test/ui-kits/surface-host-router.test.ts` MUST cover:
- **Each of the 15 methods routes to its port** and returns a well-formed `{ ok: true, value }` envelope whose `value`
  passes the matching `host-bridge.ts` guard (e.g. `launchApp` -> `isDesktopAppLaunch`, `requestFile` -> `isFilesResponse`,
  `readTheme` -> `isDesktopTheme`).
- **Fail-closed**: unknown method, wrong arity, and non-JSON/cyclic arg each return a stable `{ ok: false, error }` with
  the documented `code` and an `isHostError`-valid `error`.
- **Round-trip through `createSurfaceHost`**: wire the router as the transport
  (`createSurfaceHost((req) => router(req))`), drive a real surface call (e.g. `host.launchApp(app)` /
  `host.requestFile(...)` / `host.readTheme()`), and assert the typed SDK-level result — proving surface call -> router ->
  fake backend -> typed result agrees end-to-end.
typecheck clean. Pure, headless, deterministic (same inputs -> identical envelopes).

## Security/constraints
- Injected ports only (no ambient I/O); capability-mediated, fail-closed; pure/deterministic. Router snapshots args to
  plain JSON and rejects non-JSON/cyclic/non-finite (does not trust the caller). No remote imports; lockfile mandatory;
  no package lifecycle scripts; no FFI/native addons.
