## Objective
Headless, deterministic **view-model** for the flagship desktop's `Notifications` screen (`ui_kits/desktop/Notifications.html` / index.html),
built ONLY on `@vita/desktop-sdk` public ports (NotificationCenter + TrayModel (PSD-016)) — injected ports, NO platform internals, NO DOM/rendering (the view-model
is the pure interaction logic the rendered design binds to later).
- State: notification list (grouped by app, newest first), unread count, control-center toggles (wifi/bluetooth/dnd/etc. as tray-backed toggles). Actions: dismiss(id), dismissAll(), toggle(controlId), markRead(id). Reads/writes via the notification + tray ports; deterministic grouping/ordering; fail-closed without grants.
- Put the code under `ui_kits/desktop/viewmodels/Notifications.ts` and tests under `sdk/typescript/test/ui-kits/Notifications.test.ts`.
- Import the SDK exactly as `ui_kits/desktop/package.ts` does; use ONLY public exports.

## User value
Turns the static `Notifications` mockup into real, testable desktop behavior on the SDK — the logic the CEF-rendered HTML hydrates against.

## Non-goals
- NO DOM/CSS/rendering/CEF. NO platform internals. NO new visual design (the HTML is the design of record). Don't re-implement SDK ports — consume them.

## Acceptance
`acceptance_command` passes: deterministic unit tests cover the state transitions + fail-closed paths described above against fake SDK ports; typecheck clean. Pure, headless.

## Security/constraints
- Injected ports only (no ambient I/O); capability-mediated, fail-closed; pure/deterministic. No remote imports; lockfile; no lifecycle scripts.

## Definition of done
- `ui_kits/desktop/viewmodels/Notifications.ts` + `sdk/typescript/test/ui-kits/Notifications.test.ts`, deterministic, typecheck clean. R1.
