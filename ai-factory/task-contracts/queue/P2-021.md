## Objective
`summarizeAuditLog(events)` (controller/audit): given an ordered list of audit events (the P0-024 SDK
model), validate EVERY event via `validateAuditEvent` (fail-closed: any invalid event ⇒ typed rejection,
no summary), then produce a typed, fail-closed summary: `monotonic` (via P0-024 `isMonotonic` — false
flags tampering/gap/replay), `totalsByOutcome` (committed/rejected/rolled_back/failed counts),
`totalsByActor` (human/agent/system counts), and `recentFailures` (the last N events whose outcome is
`failed` or `rolled_back`, most-recent first). Return `{ ok: true, monotonic, totalsByOutcome,
totalsByActor, recentFailures } | { ok: false, rejections }`. Do NOT reorder events to "fix" a
non-monotonic log — report `monotonic: false` on the input as given (tamper-evidence must not be hidden).

## User value
The operator's "what has happened on this node, and is the trail intact" view (spec §17/FR-008) — every
event validated, a monotonicity check that surfaces tampering/replay rather than silently sorting it away,
and a rollup of outcomes + recent failures.

## Non-goals
- No real audit-log storage, no agent call, no network. Validate + summarize only. Do NOT modify the P0-024
  `audit-event-model`; import it. Do NOT reorder/dedupe the input to mask a non-monotonic sequence.

## Dependencies
P0-024 (audit-event model: validateAuditEvent, isMonotonic), P0-015. Merged.

## Acceptance tests
`acceptance_command` — `audit-viewer.test.ts`: a valid monotonic log ⇒ correct totals + `monotonic:true`;
a log with a repeated/decreasing sequence ⇒ `monotonic:false` (NOT silently reordered); `recentFailures`
returns failed/rolled_back most-recent-first bounded to N; any invalid event ⇒ typed rejection (no summary,
no throw); hostile input ⇒ fail-closed. Orchestrator also runs `npm run typecheck`.

## Performance & security constraints
Deterministic, no I/O/network. Fail-closed (reuse `validateAuditEvent`; never throw). Tamper-evidence
preserved (never reorder to hide non-monotonicity). Strict TS (no `any`). R2 → reviewer-gated.
