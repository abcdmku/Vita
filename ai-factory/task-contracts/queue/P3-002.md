## Objective
`denoSandboxPolicy(grantedCapabilities)` (packages/runtime) maps a package's GRANTED capabilities to a
bounded, **default-deny** Deno permission set (spec §9.3 sandboxed TS — no FFI, no lifecycle scripts,
least privilege): `{ allowNet: string[], allowRead: string[], allowWrite: string[], allowEnv: string[],
allowRun: [] }` plus the explicit deny posture. NEW validator ⇒ use `safeNormalize` for the untrusted
`grantedCapabilities` boundary, then map on the trusted plain value.
- **Default-deny**: NEVER emit `--allow-all` / unscoped `--allow-net` / `--allow-run` / `--allow-ffi`.
  Each granted capability maps to a SCOPED permission (e.g. a `net:host:port` cap → `allowNet:["host:port"]`;
  a `fs:read:/path` cap → `allowRead:["/path"]`). A capability that cannot be mapped to a bounded Deno
  permission ⇒ REJECT (fail-closed), do not widen.
- `--allow-run` and `--allow-ffi` are ALWAYS empty/denied (no subprocess, no native — §9.3). Reject any
  grant requesting them.

## User value
The concrete sandbox the package runtime runs every app under (§9.3/FR-009) — least-privilege Deno
permissions derived from the audited capability grants, never broad, never FFI/subprocess.

## Non-goals
- No real Deno spawn/execution, no network/fs, no actual `deno run`. Policy mapping + validation only.
  Do NOT change the capability/manifest source; import the grant types.

## Dependencies
P1-001 (package contract / capability vocabulary), P0-015 (safeNormalize). Both merged.

## Acceptance tests
`acceptance_command` — `sandbox.test.ts`: scoped net/read/write/env caps ⇒ correctly-scoped allowlists;
NO `--allow-all`/unscoped flags ever produced; an unmappable/over-broad cap ⇒ rejected; any run/ffi grant
⇒ rejected; empty grants ⇒ a fully-denied policy (all lists empty); fail-closed on hostile input via
safeNormalize. Orchestrator also runs `npm run typecheck`.

## Performance & security constraints
Pure/deterministic, no I/O. Default-deny (never widen; unmappable ⇒ reject). No allow-all/run/ffi. Strict
TS (no `any`). R2 → reviewer-gated (sandbox escape surface).
