`systemdUnitName` (P9-012) + boolean) — NO dialect change.

  object { name: string `systemdUnitName`; enabled: boolean (required) } } } }`. Match the agent

  agent does), `enabled` explicit presence, duplicate service-name handling, `uniqueItems`/dedup as the agent

  full-request `{"desired":{…}}` vectors) run by BOTH the TS manifest validator AND `transport.DecodeJSONRequest

  name; absent vs empty services; unknown field; dup JSON key). The corpus encodes the AGENT's accept/reject.

  the registry + wires evaluator coverage after merge (so this migration is disjoint + parallel-safe).
