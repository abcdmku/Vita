## Objective
Define the typed **package contract** every package declares (spec §9.2) plus a structural validator.
Model the declared fields as a typed `PackageContract`:
- identity + signing publisher; version + immutable digest; architectures; min CPU/RAM/storage;
  required/optional GPU/NPU capabilities (reuse the SDK `AcceleratorCapability`/preference model where
  natural — import, do not duplicate); network ingress/egress; data classes + volumes; secret
  requirements (referenced, not embedded); backup/quiesce hooks; restore verification; health checks;
  update + schema migrations; rollback limits; export formats; end-of-support date; SBOM/vuln status;
  required simulation profiles; and the package class (`ts-service | ts-extension | wasm-component |
  oci-service | microvm-service | ui-extension | native-extension`, spec §9.1).
- `validatePackageContract(c: unknown): { ok: true; contract: PackageContract } | { ok: false;
  errors: { path: string; message: string }[] }` — fail-closed; reject missing required fields,
  unknown package class, and secrets embedded inline (must be references).

## User value
The package contract is the basis for install/permission/backup/portability decisions (spec §9.2,
§13). A precise typed schema lets the catalog, permission broker, and capsule system build against it.

## Non-goals
- No signing/verification implementation, no catalog, no runtime — types + structural validation only.
- No remote schema fetching.

## Dependencies
None (may import SDK accelerator types).

## Acceptance tests
`acceptance_command`. `sdk/manifests/test/package-contract.test.ts` must prove:
1. A complete, valid contract validates and yields the typed `PackageContract`.
2. Missing a required field (e.g. version/digest/architectures) is rejected with a precise path.
3. An inline-embedded secret (rather than a reference) is rejected; an unknown package class is rejected.

## Performance & security constraints
Pure/deterministic, no I/O. Secrets referenced not embedded (spec §13.1). Fail-closed.

## Hardware profiles
