## Objective
Headless, deterministic view-model for **Window snapping + keyboard tiling assist**, built ONLY on `@vita/desktop-sdk` public ports (the WM intents + layouts ports (PSD-004/014)) — injected ports, NO
platform internals, NO DOM (pure logic the rendered desktop binds to). Code: `ui_kits/desktop/viewmodels/window-snap.ts`; test:
`sdk/typescript/test/ui-kits/WindowSnap.test.ts`. Build against CURRENT main (wave-1+2 merged). Import the SDK as
`ui_kits/desktop/package.ts` does; ONLY public exports. If a needed port is missing, define a MINIMAL injected port
interface (typed, fail-closed) fully testable against a fake now.
- Snap a focused window to halves/quarters/maximize/center/restore via WM intents; a snap-zone model (screen edges/corners) + keyboard chords (e.g. super+arrows). Deterministic geometry from the active display work area (injected, no ambient I/O); emit the WM intent and read back the resulting placement; fail-closed on invalid intents.

## User value
Extends the Vita desktop BEYOND the imported mockups with real, tested Window snapping + keyboard tiling assist behavior on the SDK — a complete desktop OS.

## Non-goals
- NO DOM/CSS/CEF, NO platform internals, NO new visual design. Consume ports; don't reimplement them.

## Acceptance
`acceptance_command` passes: deterministic tests cover the described state transitions + fail-closed paths against fakes; typecheck clean.

## Security/constraints
- Injected ports only (no ambient I/O); capability-mediated fail-closed; pure/deterministic. No remote imports; lockfile; no lifecycle scripts.

## Definition of done
- `ui_kits/desktop/viewmodels/window-snap.ts` + `sdk/typescript/test/ui-kits/WindowSnap.test.ts`, deterministic, typecheck clean. R1.
