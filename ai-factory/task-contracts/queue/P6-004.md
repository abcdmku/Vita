## Objective
A transactional capability `agent/capabilities/capsule/` that stores the node's **installed-capsule
registry** (spec §13 capsules) to a FIXED agent state path, applied atomically with rollback — the proven
nodeconfig (P1-007) pattern. A typed `Registry` = a list of `CapsuleEntry` (id + version + integrity
(SRI) + state: "installed"|"disabled"). `Handle` reads current; `Apply` validates a desired registry and
writes via a single atomic commit point (temp + rename — nothing fallible after the rename), returning a
restoring `Undo`; commit + rollback proven through the engine. Implements `Validate()` for the transport
gate (with duplicate-JSON-key rejection + canonical persisted bytes, per AGENTS.md). Injected FS facade.
- **Validate fail-closed**: capsule id well-formed (reverse-DNS or opaque id); version non-empty;
  integrity a real SRI (sha256/384/512); state from the closed set; reject DUPLICATE capsule ids; reject
  embedded capsule bytes (reference + integrity only, §13.1). Absent required field ⇒ reject (not
  defaulted). No `os/exec`, no real capsule install.

## User value
The on-host record of which capsules are installed + their integrity-pinned versions (FR-012, §13),
transactionally — the controller can read it (via /read) + stage changes. Real capsule install/run is a
later host contract.

## Non-goals
- No real capsule download/install/run/snapshot, no network. Store + validate the registry only. No
  `os/exec`. No `cmd/agentd/main.go` edits (wiring is a follow-up). No capsule byte storage (reference only).

## Dependencies
P1-006 (engine), P1-007 (atomic-file pattern). Both merged. Follow the AGENTS.md dup-key + canonical-bytes rule.

## Acceptance tests
`acceptance_command` (go test in golang:1.26) + orchestrator `go vet`. Cover: Handle reads (canonical
bytes); Apply writes + restoring Undo; transaction commit; rollback (later op fails ⇒ prior restored);
malformed id/version/SRI/state rejected; duplicate capsule ids rejected; embedded capsule bytes rejected
(§13.1); duplicate JSON keys rejected; absent required field rejected; atomic-write-failure leaves the
live file unchanged (single commit point). Injected FS.
