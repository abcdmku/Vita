## Objective
A host-context client that speaks the **existing** agentd AF_UNIX protocol
(`/run/vita-agent/agentd.sock`, the P1-035 transport in `agent/transport/server.go`) from the
unprivileged Deno host runtime, exposed as a typed `call(capability, request)` for the desktop's
`files`/`settings`/`launcher`/`apps` backends.
- Build it as `@vita/desktop-sdk`-internal under `sdk/typescript/src/desktop-sdk/agentd-host-client.ts`,
  and add tests under `sdk/typescript/test/ui-kits/agentd-host-client.test.ts`.
- **Wrap the proven transport, do NOT invent a new one.** Reuse the existing Deno AF_UNIX framing the
  runtime already ships (`os/x86_64/ts-overlay/usr/lib/vita/ts/vita/unix-socket-transport.ts` /
  `cli/src/agentd-transport.ts` — `Connection: close`, HTTP/1.1 over the unix socket, the chunked-body
  decode) via an **injected** transport function. The client never opens a socket itself in tests; the
  socket fn is a constructor dependency so the test drives a stub.
- Mirror the agentd routing/framing in `agent/transport/server.go` exactly: `GET /healthz`,
  `GET /read/<capability>`, `POST /apply` (the `{operations:[{capability,request}]}` shape), and the
  sanitized `{error:{code,message}}` body. `call(capability, request)` maps to the right method/route
  for that capability and returns a typed **Result** — never throws.
- **Socket-path scoping is load-bearing and mirrors the runtime's `--allow-read=/run/vita-agent/agentd.sock`
  + SupplementaryGroups=vita-agent posture**: the client takes an explicit socket-path **allowlist**; a
  call whose configured path is not on the allowlist returns a fail-closed result (`error.code` =
  `socket_path_forbidden`) WITHOUT touching the transport. This is the userspace mirror of the kernel
  `--allow-read/--allow-write` scope; it does not replace it.
- **Everything fails closed.** Transport throw, connect refusal, timeout, peer-closed socket,
  non-2xx agentd status, malformed/non-JSON body, oversize response → a typed `{ ok: false, error }`
  result with a stable sanitized `code`. No raw exception escapes `call(...)`; no partial value is
  returned on error.

## User value
Gives the flagship desktop (`files`/`settings`/`launcher`/`apps` backends, e.g. the view-models in
`ui_kits/desktop/viewmodels/`) one typed, capability-mediated way to reach the on-device control plane
over the same hardened socket the runtime already uses — instead of each backend re-implementing AF_UNIX
plumbing. Fail-closed semantics keep a desktop backend from acting on a half-read or spoofed reply.

## Non-goals
- NO new wire transport, NO new agentd route, NO change to `agent/transport/server.go` or the Go side.
- NO privileged effects beyond what the agentd capability already authorizes (the peer's role is derived
  by agentd from SO_PEERCRED — the client cannot elevate it).
- NO DOM/CSS/rendering/CEF; NO network sockets (AF_UNIX only, and stubbed in tests).
- Do NOT widen `--allow-read/--allow-write`, change SupplementaryGroups, or alter the unit hardening.

## Acceptance
`acceptance_command` passes. The deterministic, headless test in
`sdk/typescript/test/ui-kits/agentd-host-client.test.ts` runs against an **in-memory stub transport**
(no real socket) and proves:
- `GET /healthz` round-trips and `call(...)` returns `{ ok: true, value }` for a well-formed reply.
- A configured socket path NOT on the allowlist returns `{ ok: false, error.code: "socket_path_forbidden" }`
  and the transport is never invoked.
- Each fail-closed branch returns `{ ok: false }` with a stable sanitized code: transport throw,
  malformed/non-JSON body, non-2xx agentd `{error:{code,message}}`, timeout, and peer-closed/empty
  response — no exception escapes.
- The request envelope the client emits for `call(capability, request)` matches the agentd framing in
  `agent/transport/server.go` (method + route + `{operations:[{capability,request}]}` for apply).
No real network or unix socket is opened by the test; `typecheck` is clean.

## Security/constraints
- Injected transport only (no ambient I/O in the client core); capability-mediated; **fail-closed** on
  every error path; sanitized error codes only (never leak raw socket/path errors to callers).
- Socket-path allowlist enforced before any transport call — userspace mirror of the runtime's
  `--allow-read=/run/vita-agent/agentd.sock` scope.
- TS strict; no remote imports; lockfile mandatory; no package lifecycle scripts; no FFI/native addons.
- Deterministic: same inputs → same result; no wall-clock-dependent behavior except an injectable timeout.
