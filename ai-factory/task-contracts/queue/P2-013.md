## Objective
`applyConfig(client, plan)` (controller/apply): the end-to-end management action that PREVIEWS a plan
then SUBMITS it. Steps: (1) `previewPlan(client, plan)` (P2-008) — discover operations + reject any
unknown op; (2) ONLY if the preview is valid, call `client.apply(plan)` (P2-006); (3) return a typed
`ApplyFlowResult` { previewed: true, applied: AgentApplyResult } or { previewed: false, rejections }.
Fail-closed: a preview rejection ⇒ DO NOT submit (return the rejections); a client/apply error ⇒ a typed
flow error, never a throw. The agent client is injected (mock in tests; NO network).

## User value
The one call the management plane makes to safely apply a change: it never submits a plan with unknown
operations, and surfaces the agent's committed/rolled-back result — the preview-then-apply contract
(FR-006/007) end to end.

## Non-goals
- No real network/agent/HTTP; injected client only. No new agent or preview logic — COMPOSE P2-006 +
  P2-008. Do NOT modify the agent-client or plan-preview source; import them.

## Dependencies

## Acceptance tests
`acceptance_command` — `apply-flow.test.ts` (mock client): a plan with all-known ops ⇒ preview valid +
apply called + the committed result surfaced; a plan with an unknown op ⇒ NOT submitted (apply NOT
called), rejections returned; a client that errors during preview or apply ⇒ typed flow error (no throw);
a rolled-back agent result ⇒ surfaced typed. Assert apply is NOT called when the preview rejects.
Orchestrator also runs `npm run typecheck`.
