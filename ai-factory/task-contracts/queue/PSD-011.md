## Objective
Today the compositor only registers SOLID-color test surfaces. Add the foundation for REAL content: a surface backed by
an arbitrary **RGBA pixel buffer** uploaded as a GPU texture, so any content source (a TS rasterizer now, CEF OSR later)
can feed pixels. This is the shared substrate under all window content.
1. **Compositor API:** add `register_buffer_surface(id, width, height, &[u8] rgba)` (and an `update_buffer_surface` for
   re-upload on content change) alongside the existing solid/test-pattern path — upload the RGBA bytes to a GPU texture
   via the same backend (GLES/EGL upload; readback path stays for tests). Validate dimensions/stride/length fail-closed
   (reject mismatched buffer length). Composite + no-repaint reposition work identically for buffer surfaces.
2. **Command protocol:** extend the command-driven session (main.rs) with `registerBufferSurface <id> <w> <h> <hex-or-
   base64-rgba>` / `updateBufferSurface <id> <rgba>` so the TS CompositorPort can drive buffer content. Keep dirty-since-
   present semantics (a buffer update marks the frame dirty). Reject malformed/oversized payloads fail-closed (FAILSAFE).
3. **Readback test:** a recording-backend test composites a small buffer surface + reads it back, asserting the exact
   pixels land at the right position (proves real content, not solid fill).

## User value
The bridge from "colored rectangles" to "windows with actual content." Any renderer (TS rasterizer, CEF) becomes a
buffer producer; the compositor composites it with the existing no-repaint GPU path.

## Non-goals
- NO renderer/CEF here (this is just the buffer-surface SINK). NO font/text rendering (a later rasterizer slice). Keep
  the production OS headless — compositor stays a verification/desktop substrate.

## Acceptance
`npm run typecheck`; compositor builds for linux (rust-in-docker); cargo test incl. the buffer-surface readback +
fail-closed (bad length / oversized payload) tests. Deterministic. Orchestrator may GPU-boot a buffer-surface command
stream and confirm present=kms + the readback PNG shows the buffer content.

## Security/constraints
- Fail-closed on dimension/length/payload errors. Bounded payload size. No remote imports; --locked crates; lockfile.
  Verification/desktop substrate only, not the production OS.

## Definition of done
- `register_buffer_surface`/`update_buffer_surface` + the `registerBufferSurface`/`updateBufferSurface` commands (GPU
  upload, no-repaint, dirty-tracking, fail-closed) + readback tests proving real pixel content. R2 reviewer gate + cargo.
