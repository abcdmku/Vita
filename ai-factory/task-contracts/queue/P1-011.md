## Objective
Lay the **immutable Debian root image** foundation (spec §5; ADR-0001 Debian 13 "trixie"; Phase 1
v0.1-bootstrap). Deliver the mkosi configuration + a portable build wrapper, plus a fast OFFLINE
determinism harness — NOT a full privileged image build (that is a heavier follow-up).
- `os/common/mkosi.conf` + `os/x86_64/mkosi.conf`: a reproducible Debian-trixie root spec — pinned
  release/snapshot, an explicit package allowlist, read-only/immutable rootfs intent, NO network at
  evaluation, deterministic settings (SOURCE_DATE_EPOCH, no embedded timestamps/build host).
- `os/x86_64/build-root.mjs`: a Node wrapper that would invoke `mkosi` inside a pinned container
  (portable-first; mirror `tools/build/go-in-docker.mjs`'s container approach). It must PARSE+VALIDATE
  the config and assemble the deterministic build args, and expose a `planRootBuild()` pure function
  returning the resolved, normalized plan (so it is testable without running a privileged build).
- `os/x86_64/test/root-determinism.test.ts`: asserts `planRootBuild()` is deterministic
  (byte-identical for identical inputs), pins the snapshot/package set, sets SOURCE_DATE_EPOCH, and
  declares no network — i.e. the config is reproducible by construction.

## User value
First concrete step toward a bootable signed image (FR-001 QEMU boot, FR-023 updates). Establishes the
reproducible-build contract the whole image/update pipeline depends on.

## Non-goals
- Do NOT run a real mkosi/debootstrap build here (needs privileged container + minutes) — config +
  plan + determinism test only. No UKI/Secure Boot/RAUC/dm-verity yet (later contracts).

## Dependencies

package set. No remote imports. Strict TS (no `any`/suppressions). R2 → reviewer-gated.
