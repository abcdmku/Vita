## Objective
The largest real Phase-5 gap (spec §12.1, FR-017 in the requirements table at line ~614): **no
remote-access mesh code exists today** — `agent/capabilities/network/` has only the inbound
`network.policy` capability (`network.go`) and `agent/capabilities/capsule/ingress.go` covers
host-local capsule ingress. Add a new **`network.mesh`** capability + deterministic node model for an
**outbound-established encrypted overlay**: a node joins the mesh by *dialing out* (no inbound port is
opened, default-deny inbound is preserved per §12.2), connects directly to peers when possible, and
falls back to a replaceable encrypted relay (§12.1).

Scope is the **pure deterministic policy/state model + fail-closed validation ONLY**:
- New package `agent/capabilities/network/mesh` (package `mesh`) mirroring the structure of
  `network.go`: a `Capability` with `Name() == "network.mesh"`, `ReadRequest`/`ApplyRequest`
  (strict JSON via `jsonsafe.DecodeStrict`, `Validate()` fail-closed), an immutable
  desired-state `MeshPolicy`, and a transactional `Apply` returning a `transaction.Undo` that
  restores exact prior bytes (follow the atomicfile + undo pattern already in `network.go`).
- `MeshPolicy` is the node model: a **peer set** (each peer = stable peer id + one or more declared
  outbound egress endpoints expressed as `{proto, port, destinationCidr, interface}`), a **mesh
  identity ref** and **relay ref** (string references only — see Security), a `direct`/`relayFallback`
  reachability mode, and a derived **exposure report** (`ExposureReport`) that enumerates exactly the
  declared outbound egress and asserts no inbound listener and no host-management-network access.
- **Reuse the existing network validators** — do NOT re-implement CIDR/interface parsing. Call the
  exported `network.NormalizeCIDR`, `network.ValidInterfaceName`, `network.SourceCoversAll`, and the
  `network.Protocol`/`network.ProtoTCP`/`network.ProtoUDP` + `network.PortAll` symbols from
  `agent/capabilities/network/network.go`. Egress endpoints are canonicalized exactly as inbound rules
  are (masked canonical CIDR, concrete interface name).
- **Fail-closed rules** the validator MUST reject (each with a precise `InvalidRequestError`-style
  reason):
  - any rule that opens an **inbound listener** (the mesh is outbound-established; reject any field
    that would bind/listen — inbound is owned only by `network.policy`/capsule ingress, not mesh);
  - a **wide-open join** — `port == network.PortAll` with a destination covering all addresses
    (`network.SourceCoversAll`) — rejected unconditionally (no `unsafeWideOpen` escape hatch for mesh);
  - any egress whose destination falls inside the **host management network** or an unrelated
    application network (§12.2: "No access to host management network", "No access to unrelated
    application networks") — define the host-management range as a declared constant in the package and
    reject overlap;
  - an empty peer set, a missing identity ref, or any embedded key material (Security below).
- The `ExposureReport` is **derived deterministically** from a validated `MeshPolicy` (pure, no I/O):
  same policy → byte-identical report (spec §8.2 determinism). It lists each declared egress endpoint
  and nothing else; `Inbound` is always empty; it records the relay ref when `relayFallback` is set.

Wire the new package into the agent surface the same way `network.policy` is wired — register
`mesh.NewCapability()` in `agent/cmd/agentd/main.go` alongside `network.NewCapability()` and add the
read/apply request decoders in `agent/transport/server.go` (`mesh.Name` → apply/read), mirroring the
existing `network.Name` entries. Add a `network.mesh` conformance corpus
(`TestNetworkMeshConformanceCorpus`) in `agent/internal/capmanifest/` following the existing
`network_conformance_test.go` so the manifest dialect covers the new capability.

## User value
Delivers FR-017 ("Provide private remote access without router configuration") as a verifiable,
deterministic policy model: the node can describe joining an encrypted mesh by dialing out — no router
port-forwarding, no inbound exposure — and emit an auditable exposure report, while the default-deny
inbound posture (§12.2) is provably preserved.

## Non-goals
- **NO real cryptography, key generation, handshake, transport, or relay I/O.** Mesh identity keys,
  relay keys, and any TPM-sealed material are owner-held (§16) — this slice models *references* to them
  only and performs no network or key operations (`allowed_network: false`).
- NO nftables/netns emission, no dialing, no discovery protocol, no certificate automation — those are
  follow-on slices. This is the pure model + capability registration + conformance only.
- Do NOT modify `network.go`'s inbound semantics, `capsule/ingress.go`, or any privileged boot/storage
  path. Reuse the exported validators; do not fork them.

## Security/constraints
- **R3 / propose-only on keys.** Mesh identity keys, relay keys, and any TPM/recovery/signing material
  are **owner-held (spec §16)**; dev agents have no access. This slice declares *references* only and
  must never generate, embed, read, or commit key material. Any inline key bytes → validation REJECT.
- **R3 human-approval gate (CLAUDE.md §3 + override note):** this touches privileged Go agent
  networking surface. After independent verification, run the GPT-5.5 xhigh reviewer
  (`npm run review -- PSD-658`); merge only on `VERDICT: approve` AND a clean verification pass. Builder
  changes that drift toward real transport, key handling, or inbound exposure are a **release blocker**,
  not polish — escalate to the owner rather than merging.
- Fail-closed everywhere (`Validate()` rejects before any write); default-deny inbound preserved;
  pure/deterministic model (§8.2) — same inputs → byte-identical policy + report. Strict JSON decode
  (`jsonsafe.DecodeStrict`), no remote imports, lockfile-only, no lifecycle scripts, no FFI.
- `allowed_network: false` — acceptance runs fully offline.
