## Objective
Make the imported flagship design's THEME a first-class part of `@vita/desktop-sdk`, so any UI package + app consumes the
Vita design tokens through the SDK (not hard-coded). Pure, deterministic, headless TypeScript.
- A `themeTokens` module: parse the CSS custom properties in `ui_kits/tokens/*.css` (colors.css, spacing.css,
  typography.css, elevation.css, motion.css, fonts.css) into a TYPED `VitaThemeTokens` tree (color/space/type/elevation/
  motion/font groups; the `--name: value` pairs). Provide a deterministic parser (read the committed CSS at build/test
  time OR embed a generated snapshot — NO ambient fs at runtime; if reading files, do it in a build/test helper and embed
  the result as typed data). Expose `VitaThemeTokens` + the default token set from the SDK public surface.
- A small API the UI package/apps use: `themeVar(name)` → the CSS var reference, and the typed token catalog (so code +
  designs reference the SAME tokens). Light/dark/graphite variants where the design defines them (the kit toggles
  `theme-dark`/`mode-tiling`).
- Add to the SDK's public allow-list (PSD-021's surface test) so the theme is part of the curated boundary.

## User value
The design's tokens become the SDK's theme contract — the flagship UI package and every app render on-brand from one
source of truth, and a swapped UI package inherits/overrides the same token vocabulary.

## Non-goals
- NO rendering/CSS injection (this is the typed token DATA + accessors). NO new visual design. Don't fork PSD-021's
  surface; EXTEND it (add the theme exports to the allow-list).

## Acceptance
`acceptance_command` passes: tokens parse into the typed tree (assert specific tokens exist with expected values, e.g. an
accent color, a spacing step, a font family); `themeVar` returns the right `var(--…)`; variants resolve; the SDK
allow-list includes the theme exports; deterministic. Pure, headless.

## Security/constraints
- No ambient fs at runtime (embed/generate token data deterministically). No remote imports; lockfile. Reuse/extend
  PSD-021's public surface (no internals).

## Definition of done
- `VitaThemeTokens` + default tokens (parsed from ui_kits/tokens) + `themeVar` accessor, exported from `@vita/desktop-sdk`
  (allow-list updated), with deterministic unit tests; typecheck clean. R1.
