## Objective
Make the bootable image actually **Vita**, not bare Debian: install the Go **agentd** (the privileged system
agent, `agent/cmd/agentd/main.go`, module `github.com/vita/agent`, a loopback HTTP daemon on `127.0.0.1:8786`)
into the rootfs and run it at boot. Thin first slice — JUST the agent binary + a systemd service + its state dir.
- `os/x86_64/agent-image.conf`: pinned build params — Go image `golang:1.26`, **reproducible** build flags
  (`CGO_ENABLED=0`, `-trimpath`, `-buildvcs=false`, `-ldflags "-s -w -buildid="`, `SOURCE_DATE_EPOCH=1781308800`),
  GOOS=linux GOARCH=amd64, the build target `./cmd/agentd`, and the install manifest (binary →
  `/usr/lib/vita/agentd` mode 0755 root:root; symlink `/usr/bin/vita-agentd`; state dir `/var/lib/vita-agent`
  mode 0700). No eval-time network at PLAN time.
- `os/x86_64/agent-image.mjs`: `planAgentImage()` (pure, deterministic — same shape as the other os planners)
  returning the normalized plan: (a) the **deterministic agentd build command** (wrap `tools/build/go-in-docker.mjs`
  — `build ./cmd/agentd` with the reproducible flags above + `-o` to a fixed output path), and (b) the install
  manifest (paths/modes/owners + the systemd unit + tmpfiles). Same source → byte-identical binary. Reuse the
  canonical-path + `safeNormalize` helpers from the neighboring planners.
- `os/x86_64/agent-overlay/usr/lib/systemd/system/vita-agentd.service`: `Type=simple`,
  `ExecStart=/usr/lib/vita/agentd`, `After=network-online.target`, `Wants=network-online.target`,
  `Restart=on-failure`/`RestartSec=5s`, `AmbientCapabilities=CAP_SYS_ADMIN CAP_SYS_TIME` (the agent does
  `sethostname`/`clock_settime`), `StateDirectory=vita-agent`, `[Install] WantedBy=multi-user.target`. Enable it
  deterministically (a committed `multi-user.target.wants/vita-agentd.service` symlink OR a tmpfiles/preset — your
  call; it MUST be active after boot without a manual `systemctl enable`).
- `os/x86_64/agent-overlay/usr/lib/tmpfiles.d/vita-agent.conf`: `d /var/lib/vita-agent 0700 root root -` (the
  agent creates `/var/lib/vita-agent` mode 0700 — ensure it exists/perms at boot).

## User value
This is the first step of "it's Vita": the booted OS runs the agent that owns the 13 transactional capabilities,
not just a Debian shell. Foundation for the control-plane/capsule/PDS integration that follows.

## Non-goals
- Just the agentd binary + service + state dir (thin slice). NOT the control plane, capsules, Deno, or PDS yet
  (later slices). NO privilege-separated user yet (run as root with the two ambient caps; harden later). Do NOT
  edit `build-and-boot.mjs` — the orchestrator wires it post-merge (build agentd → stage into the overlay →
  `--extra-tree=os/x86_64/agent-overlay`). Do NOT commit the built binary (it's a build artifact).

## Dependencies
P1-011 (rootfs) merged. The agent source is `agent/` (Go 1.26). Build substrate is `tools/build/go-in-docker.mjs`
(`golang:1.26`, persistent module cache). The overlay is applied via mkosi `--extra-tree` (proven by smoke-overlay).

## Acceptance tests
`acceptance_command` — `agent-image.test.ts`: `planAgentImage()` byte-deterministic; build command carries the
reproducible flags (CGO_ENABLED=0, -trimpath, -buildvcs=false, -ldflags with -buildid=, SOURCE_DATE_EPOCH, the
fixed `-o` output path, GOOS/GOARCH); install manifest pins the paths/modes/owners; the systemd unit content is
asserted (ExecStart, ambient caps, WantedBy) and the unit is enabled (the wants-symlink/preset is present); the
tmpfiles entry creates `/var/lib/vita-agent` 0700; canonical paths (reject traversal); hostile/partial inputs
rejected via safeNormalize. Orchestrator also runs `npm run typecheck` + a `go-in-docker build ./cmd/agentd`
smoke-build to confirm agentd actually compiles with the pinned flags.

## Performance & security constraints
Deterministic/pure plan (§8.2); reproducible binary (fixed flags + SOURCE_DATE_EPOCH → byte-identical, so the
verity root hash is stable). Canonical-path validation. No production keys. Strict TS (no `any`). R2 →
reviewer-gated. The agent binds loopback only (127.0.0.1) — do not expose it.
