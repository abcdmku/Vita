## Objective
WAVE 1 of the [migration-roadmap](../migration-roadmap.md): expose the shared STRING-FIELD validation substrate
that nearly every remaining cap (update, capsule, accounts, identity, backup, pdssync) layers on. Most of the
hard logic ALREADY EXISTS in `agent/internal/capmanifest/capmanifest.go` (ported + conformance-validated in
P9-013) — this contract EXPOSES it as reusable, composable `string` field-schema OPTIONS in BOTH planes, adds
the missing pieces, and pins each to its Go reference via a frozen corpus. One dialect-touching contract.
- **`noInlineMaterial: true`** (string option) — the SERVICE-GRADE secret scanner. Reuse the EXISTING
  `capmanifest.go:containsInlineServiceMaterial` (already validated ≡ the agent `services.go:546` via the
  P9-013 services conformance) and the matching TS implementation; wire it as a reusable option on ANY string
  field. **DEPRECATE/REMOVE the WEAK existing `noInlineSecrets`** (data:/`-----BEGIN`/48-base64) — it is
  LOOSER than the agent (AGENTS.md trap 1); either remove it or alias it to the strong scanner. NOTHING may
  still reference the weak semantics.
- **`stringScreenBundle` pieces as options** (compose freely on a string field):
  `noControlChars: true` (reject `[\x00-\x1f\x7f]` — reuse `capmanifest.go:containsControlCharacter`);
  `trimmed: true` (value MUST equal Go `strings.TrimSpace(value)` — Go `unicode.IsSpace`, NOT ASCII-only);
  `maxBytes: N` (UTF-8 BYTE length ≤ N, NOT JS UTF-16 `.length` — AGENTS.md trap 4);
  `minLength: N` / treat `nonEmpty` (reject empty). Define char-vs-byte for each to MATCH the Go references.
- Both planes byte-identical; pin with `schema/capabilities/formats/string-substrate-conformance.json`
  (≥ 30 vectors total: PEM/key-assignment/seed-run/hex≥32/std+url-base64≥48 ACCEPTED-as-material → reject;
  benign strings → pass; control chars; surrounding Unicode whitespace; multibyte strings at the byte boundary
  e.g. a 3-byte char making byteLen=maxBytes+2 while `.length`=maxBytes-1) run by BOTH planes; drift fails CI.
- NO cap manifest/migration here (the consuming caps wire these options in later contracts). NO cross-field
  primitive. NO agent cap change — the agent reference functions are the GROUND TRUTH; do not alter them.

## User value
The reusable string substrate every remaining cap needs — and it KILLS the loose `noInlineSecrets` parity
trap repo-wide, so no future migration can accidentally use the weak scanner.
