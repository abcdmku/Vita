## Objective
A transactional capability `agent/capabilities/backup/` that stores a validated **backup policy**
desired-state (the on-host counterpart to the SDK P0-020 backup model) to a FIXED agent state path,
applied atomically with rollback — the proven nodeconfig (P1-007) pattern. A typed `Policy` = schedule
(cron-like or interval), targets (referenced by id), retention (count + max age days), and a
recovery-key reference. `Handle` reads current; `Apply` validates a desired policy and writes via a
single atomic commit point (temp + rename — nothing fallible after the rename), returning a restoring
`Undo`; commit + rollback proven through the engine. Implements `Validate()` for the transport gate.
Injected FS facade for tests.
- **Validate fail-closed**: schedule well-formed; retention count 1-1000 + maxAgeDays 1-3650 (when
  present, use a pointer to distinguish absent from explicit 0 — the absent≠zero rule); targets non-empty,
  referenced by id; **secrets-as-references (§13.1)**: recovery-key referenced, NEVER inline key material.
  Absent required field ⇒ reject (not defaulted). No `os/exec`, no real backup execution.

## User value
The on-host backup desired-state (FR-015) the controller manages — schedule + retention + recovery-key
reference, transactionally. Real backup run/restore is a later host contract.

## Non-goals
- No real backup execution/snapshot/upload/restore, no crypto, no network. Store + validate the policy
  only. No `os/exec`. No `cmd/agentd/main.go` edits (wiring is a follow-up).

## Dependencies
P1-006 (engine), P1-007 (atomic-file pattern). Both merged. Mirror the P0-020 SDK invariants (§13.1).

## Acceptance tests
`acceptance_command` (go test in golang:1.26) + orchestrator `go vet`. Cover: Handle reads; Apply writes
+ restoring Undo; transaction commit; rollback (later op fails ⇒ prior restored); malformed schedule /
out-of-range retention / empty targets rejected; **explicit-zero retention rejected** (absent≠zero);
embedded recovery-key material rejected (§13.1); absent required field rejected; atomic-write-failure
leaves the live file unchanged (single commit point). Injected FS.

incomplete/missing; pointer for optional-reject-zero fields). §13.1 secrets-as-references. No `os/exec`.
