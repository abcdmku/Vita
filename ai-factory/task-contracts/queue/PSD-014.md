## Objective
Extend the merged WM policy (PSD-004, pure/deterministic) with real window-management behavior, all as pure functions
over the window model (no I/O, no GPU — the policy emits intents the existing seam (PSD-009) turns into compositor
commands):
- **Tiling layouts:** given N windows + a workspace rect, compute placements for `floating` (current), `columns`,
  `master-stack`, and `grid` layouts. Deterministic geometry; honor min sizes + a configurable gap; match the existing
  Placement/zone shape so PSD-009 reconciles them as no-repaint moves.
- **Workspaces:** multiple named workspaces; windows belong to one; switching workspace shows that set + hides others
  (visibility intents). Deterministic active-workspace + per-workspace layout.
- **Focus + restack:** focus-next/prev, focus-follows-policy, raise-on-focus → z-order intents (consumed by PSD-009's
  setFocus/restack path). Deterministic focus ring.
Reuse PSD-004's types + the desktop-substrate intent shapes; do NOT fork them. No new I/O.

## User value
Turns the desktop from "windows wherever placed" into a real WM: tiling, workspaces, keyboard-friendly focus — the
behavior a usable desktop needs, expressed as pure policy that drives the GPU through the existing seam.

## Non-goals
- NO GPU/compositor/seam changes (emit intents; PSD-009 already consumes them). NO input handling (a later slice maps
  keys→WM actions). NO animation.

## Acceptance
`acceptance_command` passes: each layout computes correct deterministic geometry (incl. min-size/gap edge cases);
workspace switch shows/hides the right sets; focus ring + restack are deterministic; comprehensive unit tests. Pure,
headless; no boot marker.

## Security/constraints
- Pure/deterministic, no ambient I/O; reuse PSD-004 types. No remote imports; lockfile; no lifecycle scripts.

## Definition of done
- Tiling (floating/columns/master-stack/grid) + workspaces + focus/restack as pure WM policy over the merged model,
  emitting the existing intent shapes; comprehensive deterministic unit tests; typecheck clean. R1 review + integrate.
