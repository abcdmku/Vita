## Objective
Headless, deterministic view-model for **Workspaces / virtual desktops**, built ONLY on `@vita/desktop-sdk` public ports (the WM workspaces/layouts ports (PSD-014)) — injected ports, NO
platform internals, NO DOM (pure logic the rendered desktop binds to). Code: `ui_kits/desktop/viewmodels/workspaces.ts`; test:
`sdk/typescript/test/ui-kits/Workspaces.test.ts`. Build against CURRENT main (wave-1+2 merged). Import the SDK as
`ui_kits/desktop/package.ts` does; ONLY public exports. If a needed port is missing, define a MINIMAL injected port
interface (typed, fail-closed) fully testable against a fake now.
- Ordered workspaces with active id + per-workspace window set. Actions: create(), remove(id), switch(id), rename(id,name), moveWindowToWorkspace(win,id). Deterministic ordering; fail-closed on invalid ids; reads back state from the WM port.

## User value
Extends the Vita desktop BEYOND the imported mockups with real, tested Workspaces / virtual desktops behavior on the SDK — a complete desktop OS.

## Non-goals
- NO DOM/CSS/CEF, NO platform internals, NO new visual design. Consume ports; don't reimplement them.

## Acceptance
`acceptance_command` passes: deterministic tests cover the described state transitions + fail-closed paths against fakes; typecheck clean.

## Security/constraints
- Injected ports only (no ambient I/O); capability-mediated fail-closed; pure/deterministic. No remote imports; lockfile; no lifecycle scripts.

## Definition of done
- `ui_kits/desktop/viewmodels/workspaces.ts` + `sdk/typescript/test/ui-kits/Workspaces.test.ts`, deterministic, typecheck clean. R1.
