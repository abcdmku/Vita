## Objective
A typed TypeScript client (`controller/agent-client/`) the controller uses to talk to the Go agent's
loopback HTTP transport (P1-008): `getHealth()` (GET /healthz), `getCapabilities()` (GET /capabilities),
and `apply(plan)` (POST /apply). The request/response JSON MUST match the agent exactly — **read
`agent/transport/server.go` and its typed request/response structs** and mirror them (the agent decodes
with `DisallowUnknownFields`, so the client must send exactly the accepted shape; unknown/missing fields
would be rejected). Reuse the SDK plan/operation types where they already model the apply payload.
- The client takes an **injected transport** (a `fetch`-like function) so tests use a mock agent — NO
  real socket, no network.
- **Fail-closed on RESPONSES too** (the agent is trusted-ish but defense-in-depth): parse every response
  through `safeNormalize` + a typed validator; a malformed/unexpected response ⇒ a typed client error,
  never a throw or a silently-trusted object.

## User value
This is the controller↔agent seam — the management plane can finally read node health/capabilities and
submit transactional plans (FR-004/006/007/008). Everything UniFi-style in the controller builds on it.

## Non-goals
- No real HTTP/socket/network, no auth/TLS (loopback trust, like P1-008). No UI. No agent changes.
- Do NOT change the agent's wire format — MATCH it.

## Dependencies
P1-008 (agent transport + its wire types) — merged. SDK plan types + `safeNormalize` — merged.

## Acceptance tests
`acceptance_command` — `agent-client.test.ts` against a MOCK transport: `getHealth`/`getCapabilities`
parse a well-formed agent response into typed values; `apply` serializes a typed plan to the EXACT agent
wire shape (assert the bytes the mock receives match what the Go decoder accepts) and parses the
committed/rolled-back result; a malformed/garbage/partial agent response ⇒ a typed client error (no throw),
verified fail-closed via safeNormalize; a non-2xx agent error maps to a typed client error.

## Performance & security constraints
Deterministic. Injected transport (no network). Fail-closed response parsing via `safeNormalize` (never
throw). Wire shape matches the agent's `DisallowUnknownFields` decoder exactly. Strict TS (no `any`).
R2 → reviewer-gated.
