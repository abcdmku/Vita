## Objective
Add the notifications + system-tray MODEL to the merged shell (PSD-005 surface model + PSD-006 chrome) as pure,
deterministic TypeScript that produces shell surfaces the WM/compositor place — no I/O, no GPU.
- **Notifications:** a `NotificationCenter` model — post/dismiss/expire (with a deterministic, INJECTED clock — no
  ambient time), priority ordering, max-visible + overflow, per-app grouping, and an action set per notification.
  Emits a notification-surface description (for the panel + a toast stack) in the PSD-005 surface shape.
- **System tray:** a `TrayModel` — registered status items (id, icon ref, tooltip, menu), deterministic ordering,
  click/menu intents. Emits a tray surface for the panel (PSD-006).
- **Capability-mediated:** posting a notification / registering a tray item goes through an INJECTED capability port
  (the app's grant), fail-closed if an app lacks the grant — no ambient posting. Pure + deterministic + unit-tested
  (incl. expiry via the injected clock + the fail-closed-without-grant case).

## User value
Two core shell affordances (notifications + tray) every desktop needs, as deterministic capability-gated models that
slot into the merged shell/chrome and drive surfaces through the existing pipeline.

## Non-goals
- NO GPU/compositor/rendering (emit surface descriptions; the seam/compositor render them). NO real timers (injected
  clock). NO network. Don't fork PSD-005/PSD-006 types — reuse them.

## Acceptance
`acceptance_command` passes: post/dismiss/expire/priority/grouping/overflow are deterministic (clock injected); tray
register/order/menu deterministic; capability fail-closed without grant; comprehensive unit tests. Pure, headless.

## Security/constraints
- Capability-mediated (injected grant port), fail-closed; pure/deterministic, injected clock, no ambient I/O. No remote
  imports; lockfile; no lifecycle scripts.

## Definition of done
- `NotificationCenter` + `TrayModel` (capability-gated, injected clock, emit PSD-005 surface shapes) with comprehensive
  deterministic unit tests incl. fail-closed; typecheck clean. R1 review + integrate.
