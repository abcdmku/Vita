## Objective
Remove the canned `Healthy: true` placeholder in agentd's `/healthz` handler and replace it with a
**real, measured aggregate health signal** folded from live subsystem state.

Evidence: `agent/status/status.go:61-77` — `(*handler).status()` builds `Status{ ..., Healthy: true }`
**unconditionally**. The `Healthy bool` field (`agent/status/status.go:15`) is documented/intended as an
aggregate health signal but is never computed from any subsystem; capabilities and uptime are real, only
the boolean is hardcoded. A node with a down capsule, an unready transport, or degraded storage still
reports `"healthy": true`, which is a false readiness signal that can mask an unhealthy node from
operators and orchestration.

Required change:
- Add an injected **health source** (an interface/func field on `handler`, wired via `newHandler`/`NewHandler`)
  that returns the measured aggregate health. Compute `Healthy` by folding the *worst-of* across the real
  inputs that are available: capsule `Supervisor.Snapshot()` worst-of workload `Health`
  (`agent/internal/capsule-runtime/health.go:249` — `StatusDown`/`StatusUnhealthy`/`StatusUnknown` ⇒ not healthy),
  transport/registry readiness, and `storagehealth` (`agent/internal/storagehealth/storagehealth.go` —
  `StatusDegraded`/`StatusUnknown` ⇒ not healthy). The fold MUST be fail-closed: any unhealthy/degraded/unknown/unready
  input ⇒ `Healthy: false`; `Healthy: true` ONLY when every consulted subsystem reports healthy.
- Inject the health source so it is unit-testable with fakes (no ambient I/O, no real systemctl/sysfs in tests),
  exactly mirroring how `now clock` is already injected through `newHandler`.
- `NewHandler` keeps a usable production default. Do NOT widen the JSON `/healthz` body to leak secrets
  (the existing `secret`/`token`/`password` guard in the test must keep passing). Keep capabilities/uptime
  behavior unchanged; ordering/determinism preserved.

If, and only if, the team concludes `/healthz` must remain strict process-liveness, the alternative is to
rename/document the field as `liveness` and add a separate `readiness` (or `aggregateHealth`) field that
carries the measured fold above — the canned boolean must not survive under the name `Healthy` either way.
Default to computing `Healthy` from real state.

## User value
Operators and on-device control plane get a truthful node-health signal: a node with a down capsule,
unready transport, or degraded storage reports `"healthy": false` instead of a canned `true`, so failing
nodes are visible instead of silently masked.

## Non-goals
- No new HTTP routes/methods beyond the existing `/healthz` GET. No network calls (probes are injected/faked in tests).
- Do not re-implement the capsule supervisor, storagehealth, or transport — consume their existing snapshot/report types.
- No change to capabilities-list or uptime semantics. No secret/PII added to the response body.

## Acceptance
`acceptance_command` passes: `cd agent && go test ./status/`.

The test suite (`agent/status/status_test.go`) MUST, against injected/fake health inputs, assert ALL of:
1. **Placeholder is gone (negative):** with a fake health source reporting an unhealthy/degraded/unknown
   subsystem (e.g. a `StatusDown` capsule workload, or `StatusDegraded` storage), `/healthz` returns
   `"healthy": false`. A grep/AST check that no code path sets `Healthy` to a literal `true` independent of
   the injected source (the boolean must come from the injected health source, not a constant).
2. **Real healthy path (positive):** with a fake source reporting every consulted subsystem healthy,
   `/healthz` returns `"healthy": true`.
3. **Fail-closed worst-of:** with multiple inputs where at least one is not-healthy, the aggregate is
   `false` (worst-of dominates); when the source has no information (empty/unknown), it does NOT silently
   report healthy.
4. Existing assertions still hold: 200 + `application/json`, real version/uptime/sorted capabilities, and
   the `secret`/`token`/`password` body guard.

Tests must be deterministic and hermetic (injected clock + injected health source; no real systemctl, sysfs,
or sockets).

## Security/constraints
- Fail-closed aggregation: unknown/unready/degraded ⇒ not healthy. No secrets/PII in the `/healthz` body.
- Injected dependencies only in tests (no ambient I/O); deterministic. R3 — privileged agent boot/identity-adjacent
  surface: no behavior change to capability gating; response stays minimal.
